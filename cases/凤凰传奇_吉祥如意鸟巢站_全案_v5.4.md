### 2.2 生涯阶段判定：为什么是"复兴期后段 + 收官期"

| 事实 | 指向 |
|---|---|
| 彩铃时代（2006 彩铃下载 7,900 万次）→ 广场舞时代 → 2021《海底》B 站翻红（全网播放 3.4 亿/日，B 站百大 UP 主 2021、2023） | 完成**代际扩张**，非单纯怀旧盘 |
| 年龄结构 95 后占六成以上；台州站 25-29 岁 34.8%；B 站粉丝 90/00 后 78.67% | 年轻化已完成，**不是"中老年专属"品类逻辑** |
| 2024 鸟巢 2 场 → 2026 鸟巢 6 场（场次 ×3） | 需求仍在扩张，处于**复兴高点** |
| 2026 为 2027 世锦赛前鸟巢最后一年有演唱会 | 本轮具备**阶段性终点的客观属性** |

> 判定结论：**叙事强度"高-极高"**，稀缺款可做；但因"复兴"而非"告别"，叙事必须落在"我们还在最好的时候"，**不能落在"最后一次"**——这是语气问题，也是舆情风险问题。

### 2.3 IP 资产盘点与缺口（决定符号从哪里长出来）

| 资产类型 | 有 / 无 | 具体 | 缺口对设计的影响 |

| 卡通 / IP 形象 | **无** | 无可延展的吉祥物 | 放弃娃类、盲盒家族、挂件家族——做了也没有认知承接 |

### 2.5 → 决策含义

### 3.6 审美禁区（设计团队必读）

| 禁忌 | 为什么 | 正确替代 |
|---|---|---|
| 艺人面部照片做主视觉 | 粉丝视为"廉价应援物"，与"不装"人设冲突 | 歌词排版 / 抽象凤凰 / 泼墨山形 |
| 红金满印、烫金大字 | 掉进"庙会感"，与国风高级感相反 | 朱砂红单色 + 留白 + 小字 |
| Q 版卡通化、圆体字 | 与歌手气质断层，且无 IP 形象承接 | 剪影 / 写意笔触 / 宋黑体 |
| 把"土"当卖点做成显性文案 | 自嘲是粉丝的特权，品牌做就是冒犯 | 只在梗类小件上轻用，主 KV 不用 |
| 荧光色、渐变紫蓝 | 撞偶像团视觉，粉丝会立刻识别为"不是我们的场" | 哑光、低饱和、纸感 |

### 3.7 我们不知道什么

1. 六场观众的年龄/性别/跨城结构实际分布（票务方有数据，未公开）——现为 B 级推断
2. "回家不亮"话题的真实转化规模（热帖量 ≠ 购买意愿）
3. 生日场（11.6）的人群是否与其他场显著不同——若不同，需独立配货

### 3.8 → 决策含义

- **D2-01**：无组织型粉丝 → 不做抢购机制，做"到场即可买 + 选号"；运营重心在公域内容
- **D2-02**：全民合唱亚型 → 应援类 ×0.3，参与型/解痛点型 ×1.2
- **D2-03**：国风 + 歌词合计 55% → 主视觉走"泼墨 + 大字歌词"，服装主色限定墨黑/宣纸白/朱砂红单色
- **D2-04**：跨城 40-50% → 所有产品必须满足"能塞进背包、不怕压、无液体"（这条直接否掉了大件摆件以外的体积方案）
- **D2-05**：痛点明确（棒子回家不亮）→ 至少一款产品专门解决它，这是全场最高分的由来
- **D2-06**：家庭/结伴比例高 → 至少两组"套装"，且礼盒要"送得出手"

| 开场 | 约 20 分钟 | 壮阔、集体出发 | 《山河图》《策马奔腾》 | 手灯、应援类（弱） |
| 国风段 | 约 40 分钟 | 民族自豪、投入 | 《奢香夫人》《我从草原来》 | 钥匙扣、徽章、帆布袋 |
| 抒情段 | 约 30 分钟 | 安静、被托住、眼眶发热 | 《荷塘月色》《海底》 | 歌词卡、NFC 卡、票根套 |
| 狂欢段 | 约 40 分钟 | 零门槛快乐、跑调也没关系 | 《最炫民族风》《自由飞翔》 | 贴纸、T恤、毛巾 |
| 返场 | 约 20 分钟 | 不舍、想带走一点什么 | 《吉祥如意》《感到幸福你就拍拍手》 | 礼盒、相框、编号摆件 |

> 这张表不是"情绪分析"，它直接决定三件事：**陈列动线**（进场口卖低价、中场卖高客单、散场口卖收藏）、**补货时点**（狂欢段后 T恤与毛巾必然断码）、**限购触发**（返场前 15 分钟是礼盒抢购窗口）。

### 4.3 篇章结构

| 篇章 | 情绪 | 代表曲目 | 绑定品类方向 |
|---|---|---|---|
| ① 启程 | 苍茫、辽阔、集体出发 | 《月亮之上》《自由飞翔》 | 帆布袋、速干毛巾 |
| ② 山河 | 民族、壮阔、家国式浪漫 | 《奢香夫人》《荷塘月色》 | 亚克力钥匙扣、金属徽章 |
| ③ 上岸 | 安静、被托住、眼眶发热 | 《海底》 | NFC 卡、光栅歌词卡 |
| ④ 狂欢 | 零门槛快乐、跑调也没关系 | 《最炫民族风》 | 手灯、T恤、贴纸 |
| ⑤ 散场 | 不舍、想带走一点什么 | 返场 | 编号礼盒、收藏相框 |

> 情绪曲线决定**陈列动线**：进场先过 ①（低价引流）→ 中场 ②③（高客单，情绪最软时）→ 散场前 ④⑤（冲动 + 收藏）。散场口的礼盒与相框是全场毛利最高的一段。

### 4.4 场次结构变量（六场连开的零成本增量）

| 场次 | 性质 | 差异化做法 |
|---|---|---|
| 10.30 首场（周五） | 媒体场 + 口碑场 | 首发限量、全场内容拍摄；首日售罄数据决定返单 |
| 10.31-11.1 | 周末主战场 | 全品类齐发，配额最足 |
| **11.6 生日限定场** | **官方标注的生日场（曾毅生日档）** | **独立配色 + 独立编号段**，同款可溢价 10-15%；需提前 45 天排产 |
| 11.7-11.8 | 末段 + 收官 | 礼盒、相框、编号摆件集中投放；末场留"告别"文案位 |
| 11.2-11.5 空档 | **4 天返单窗口** | 首段售罄款加急补货，直送第二段 |

> **六场不做差异化，等于把六次机会当成一次用。** 同一款换配色换编号段，成本几乎不变，溢价 10-15%，还能让"六场集齐"成为二次购买理由。

### 4.5 → 决策含义

- **D3-01**：情绪最软在抒情段（《海底》）→ 高客单的 NFC/歌词类必须摆在抒情段前后的中场区，而不是进场口
- **D3-02**：散场口是毛利最高段 → 礼盒/相框/编号摆件只放散场动线，进场口不放
- **D3-03**：11.6 生日场 → 必须做独立配色，且这是唯一值得提前开模排产的场次
- **D3-04**：11.2-11.5 有 4 天空档 → 返单可行，首批不必按六场总量备货，可按"首段 + 保险系数"
- **D3-05**：28 首 / 150 分钟的高密度曲目 → 歌词类 SKU 只选 5 句以内的高辨识句，多了反而稀释

## 第 5 章｜D4 城市与场馆（含"闭馆前一季"变量）

### 5.1 城市四个数

| 指标 | 取值 | 依据 |
|---|---|---|
| 推荐客单价 | ¥80-120（加权 ¥83） | A：票价跨度 380-1380；B：同场馆历史项目客单价 |
| 限量款接受度 | **高** | B：北京收藏文化 + 全国粉丝跨城集中，编号款溢价空间大 |
| 跨城观演比例 | 40-50% | B：六场连开 + 全国粉丝赴京 |
| 地缘叙事可用性 | **中** | B：北京不是他们的"家乡"，但鸟巢是国民地标——**地缘故事讲不通，场馆故事讲得通** |

> 这条判断很重要：很多方案会在北京站硬套"北京元素"（胡同、京腔、故宫），但这个项目的情绪落点是"六万人合唱"，不是"北京"。硬套地域元素会变成旅游纪念品。

### 5.2 场馆 IP 强度（六维，各 10 分）

| 维度 | 分数 | 依据 |
|---|---|---|
| 艺人国民度 | 10/10 | 十首以上国民级曲目，全年龄覆盖 |
| 粉丝忠诚度 | 8/10 | 无饭圈组织，但复购与跨城意愿强；忠诚体现在"到场"而非"打投" |
| 本场稀缺性 | 9/10 | 六场连开 + 2026 收官 + 2027 世锦赛前最后一年 |
| 社交传播力 | 8/10 | 梗文化传播极强，但非"热搜体质" |
| 场馆品牌价值 | 9/10 | 国家体育场·鸟巢，国家级地标 |
| **综合** | **9.0/10** | |

### 5.3 联名类型判定

| 项 | 分数 |
|---|---|
| 艺人 IP 强度 | 9.0 |
| 场馆品牌价值 | 9.0 |
| 差值 | 0 |
| **判定** | **强平衡型**（两者均≥8 且差值≤1） |

**依规则，场馆元素可上辅助层，限量款可上主视觉。但本方案主动降一级，只上辅助层**，理由：粉丝买的是"大合唱"，不是"鸟巢"。把场馆做成主视觉，是把收藏者的兴趣强加给粉丝——这正是谢霆锋式"品牌自嗨"的翻版。

### 5.4 场馆元素三层策略

| 层级 | 具体用法 | 本项目取舍 |
|---|---|---|
| 隐性层（全 SKU 通用） | 水洗标/内页印经纬度 39°59'35"N 116°23'26"E、六场日期矩阵、"2026" | ✅ 全线使用 |
| 辅助层（多数 SKU） | 钢构线条作走边、封套底纹、编号卡背面印章 | ✅ 用于礼盒、相框、帆布袋 |
| 主视觉层 | 鸟巢建筑构图做主图 | ❌ **主动不用**（除礼盒内页一行小字） |

### 5.5 档期结构：2026 鸟巢的"第一场"与"最后一场"

| 事实 | 性质 | 用法 |
|---|---|---|
| 2026 鸟巢首场是黄子弘凡（"开门红"），场馆方与艺人方都有做好动机 | 场馆全年运营的"开" | 说明场馆侧存在**仪式化运营意愿**，不是纯收租方 |
| 凤凰传奇是 2026 鸟巢收官场 | "收" | **授权谈判筹码 + 稀缺机制来源** |
| 2027 年鸟巢因田径世锦赛无演唱会安排 → 未来一年鸟巢无明星演唱会 | 阶段性绝唱（可验证事实） | ①场馆联名的正当性 ②编号/纪念的稀缺依据 ③**不可作为主卖点** |

**三条使用规则（本章最重要的部分）：**

1. **合法性上可用，语气上要克制。** "2026 年鸟巢最后一场演唱会"是**事实陈述**，可用；"绝版""永不再有""最后的机会"属极限词，禁用（合规第 6 条）。
2. **分层叙事，不做主视觉。** 第一层给粉丝：大合唱、歌词、玩梗——这是他们真正买的东西。第二层给收藏者：编号、日期、场馆隐性印记、闭馆前最后一季——做成**礼盒内页的一行小字、编号卡背面的印章**，而不是海报上的大字。若把"绝唱"做成主视觉，会显得刻意收割，与凤凰传奇"不装"的调性直接冲突。
3. **对场馆方是谈判筹码，不是宣传素材。** 提法建议：以"2026 鸟巢收官纪念"为名做**场馆联名款**，换取：场馆元素授权 + 展位位置 + 官方渠道背书 + 可能的联合宣发。场馆方全年需要一个漂亮收尾，这是双方动机对齐的窗口——**这是本项目独有的、不可复制的资源**。

### 5.6 我们不知道什么

1. 场馆方是否已有其他品牌的收官联名在谈（若有，稀缺性会被稀释）
2. 六场的确切可售座位数（按 6.2-6.5 万/场区间测算，非精确值）
3. 2027 世锦赛期间鸟巢是否完全停办商业演出（影响"未来一年"表述的严谨性）

### 5.7 → 决策含义

- **D4-01**：强平衡型但主动降级 → 场馆元素只做隐性/辅助层，主视觉走"歌词 + 泼墨"
- **D4-02**：跨城 40-50% + 客单价 ¥83 → 主推价格带落在 ¥45-149，礼盒定 ¥499 需强叙事支撑
- **D4-03**：地缘叙事不可用 → 不做"北京元素"，做"这一夜"
- **D4-04**：收官档期 → 授权谈判以"场馆收官纪念"切入（见 6.7）
- **D4-05**：档期稀缺只进内页 → 主 KV 永不出现"最后""绝唱"字样

### 6.6 合同重点六条

1. **双人共签**：肖像、签名、背书类物料须玲花与曾毅双方确认（组合特有）

3. **渠道含线上**：否则 λ 按 1.0，方案第 10 章的长尾部分全部作废
4. **期限覆盖演后 60-90 天**：否则返单与尾货流转无从谈起
5. **审核超时视为通过**：没有这一条，审核一定吃掉生产窗口
6. **分成口径写明基数**：按吊牌价还是实收、是否在场地分成之后计算——这一条差 5 个点毛利

- 不与官方中控棒竞争（不做第二根"场内应援棒"）
- 不与巡演主视觉撞车（原创凤凰图腾，非舞台视觉搬运）

- 收集文化要用起来：套组叙事、编号连续性、六场不同配色

### 7.3 → 决策含义

- **D6-01**：无 A/C/E 类分流 → 购买意愿 w 可取中高段（0.24 基准），不必保守
- **D6-02**：k=0.95 → 产量可按基准排，不需要为分流额外打折
- **D6-03**：B 类收集文化 → 编号与场次系统是本项目的**核心机制**，不是附加装饰
- **D6-04**：D 类通货化风险 → 必须有至少 2 款"只有鸟巢才成立"的款，否则整套矩阵可被任一站点复制

### 8.1 → 决策含义

- **D7-01**：小件 + 异形占实证 25-65% → 矩阵重心放在"小件 + 解痛点异形"，不押服装
- **D7-02**：T恤份额仅 5-12% → 定 1 款即可，作用在毛利与视觉统一，不指望走量
- **D7-03**：解痛点与收藏是空位 → 手灯类、相框类、礼盒类三个方向构成差异化主轴，具体款式在第 9 章落定
- **D7-04**：趋势结论有时效 → 本版结论有效期 90 天，T-60 需复检一次

### 15.3 现场陈列与限购
