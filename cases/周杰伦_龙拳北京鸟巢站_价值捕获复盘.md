# 周杰伦「龙拳·北京·嘉年华2026」鸟巢站
## 周边表现专业评估 —— 兼论"顶流卖不动"这个说法错在哪

> 评估日期：2026-10-31｜CMIS **v6.2** 归因样本（v6.1 版有证据错误，本文为修正版）
> 结论先行：**"我方（定制款/单点）能捕获的流水，被四个结构性约束压到了 ≈13%。**
> **这与需求旺不旺无关——即使需求一般，这个上限也不变。**
>
> ⚠️ **v6.2 重要更正**：v6.1 曾把「6/27 暴雨引发的哄抢、售卖点被洗劫、派出所介入」当作
> "需求过热、供给不足"的核心证据。**这是错的。**
> 那是**治安事件导致的非交易性库存流失**，不是购买行为，不能证明任何需求。该证据已整体撤销。
>
> 本文重算后的落点：**③ 没份额 + ④ 归别人 成立；① 卖不动 不可排除；② 不够卖 已撤销。**
> 结论不但没有削弱，反而更稳——因为它**不再依赖任何需求侧证据**（详见第二节）。

## 一、先看证据：周边需求侧，我们其实什么都没证明

### 1.1 已确认的事实（门票侧）

| 指标 | 实况 | 来源口径 |
|------|------|---------|
| 场次 | 2026-06-26 / 27 / 28，鸟巢连开 3 场 | 鸟巢官方观演提示 |
| 到场人次 | **累计近 20 万，场均 6.5 万，上座率 100%** | 多家媒体一致口径 |
| 票务热度 | 大麦"想看"**260 万+**，**近 180 万人**参与抢票；10.6 万张可售票秒罄 | 中华网/票务报道 |
| 票价带 | 看台 ¥580/780/1080/1380；内场 ¥1980/2180/2380/2580 | 中评社 |
| 稀缺叙事 | 出道 25 年首次鸟巢个人专场，兑现 2008 年遗留的**18 年鸟巢之约** | 官方物料 |

> ⚠️ **以上五项全部是门票侧数据，对周边销量零证明力。**
> 凤凰传奇案刚证明过：门票 1 分钟售罄、观众 66% 是 18-29 岁，周边照样滞销。
> **用上座率倒推周边销量，是 CMIS 已明令禁止的动作**（`SKILL.md` 原则 20、23c）。

### 1.2 被撤销的证据（v6.1 曾误用）

| 现象 | v6.1 的解读 | **v6.2 判定** |
|---|---|---|
| 6/27 暴雨，观众涌入周边区避雨，演变为哄抢，毛毯玩偶被成包取走，多个售卖点被"洗劫一空"，派出所介入 | "需求过热的铁证" | ❌ **无效证据**。治安事件 = **非交易性库存流失**，不是购买行为 |
| 黄牛把钥匙扣炒到 ¥399 | "一级定价过低" | ◐ **弱-中**。是**挂价**，未见成交；且限量稀缺本身即可造成套利空间 |
| 官方反复写"数量有限，售完即止" | "供给跟不上" | ❌ **无效**。营销套话，与真实售罄无关 |

**为什么哄抢不能当需求证据——这条比本案本身更重要：**

哄抢与真实抢购在外观上**完全一致**：人群拥挤、货架见空、"售完即止"。
但前者反映**秩序失控**，后者反映**购买意愿**。**只有收款记录能区分。**
把抢劫读作抢购，会得出完全相反的处方——从"先看份额"变成"赶紧加货"。

> **判别法（已写入 CMIS v6.2）：该时段有没有对应的收款记录？没有 → 一律按库存流失处理。**
> **看收银机，不要看货架。**

### 1.3 所以，需求侧的真实状态是：未知

| 口径判定 | 结论 | 理由 |
|---|---|---|
| ① 卖不动 | **◐ 不可排除** | 周边侧无任何一级需求证据（无我方成交售罄率、无回款数据） |
| ② 不够卖 | **❌ 撤销** | 唯一支撑（哄抢）已作废；¥399 挂价不足以单独支撑 |
| ③ 没份额 | ✅ **成立** | 结构性证据充分，见第三节 |
| ④ 归别人 | ✅ **成立** | 结构性证据充分，见第三节 |

> **证据不足时不得硬归类。** 三项判定证据都拿不到，就写"① 不可排除、③④ 成立"，
> **不默认 ①** —— 就像不能因为没测体温就宣布发烧。

### 1.4 外界两条猜测：仍不成立，但理由要换

| 猜测 | 判定 | 理由（**修正后**） |
|---|---|---|
| ❌ "经纪公司审美出了问题" | 不成立 | 审美问题表现为**不动销**。但我们**没有不动销的证据**——所以准确说法是"**无法证实**"，而非"已证伪"（v6.1 曾用哄抢证伪，该论证已作废） |
| ❌ "管理混乱把产品环节阻断了" | **不成立** | 现场六级主体 + 统一编号 + 统一自提核销 + 统一售后，组织度极高。**这条不受证据撤销影响** |

## 二·B、既然需求未知，为什么还能下结论？

因为 **V 是一个结构性判定，不依赖需求侧证据。**

想一想这四个约束，哪一个需要知道"周边卖得好不好"才成立？

| 约束 | 需要需求数据吗 |
|---|:---:|
| 现场有 6 个并行官方主体在分同一个钱包 | ❌ 不需要——数主体就行 |
| 我方货架 ¥3-128，同场 PHANTACi ¥262-672 | ❌ 不需要——看价签就行 |
| 我方窗口 3 天，IP 全域活动 23 天 | ❌ 不需要——看日历就行 |
| 周同学已授权 200+ 家，品类占满 | ❌ 不需要——查授权记录就行 |

**四条全都不需要。** 所以无论周边是卖爆了还是卖砸了，
**我方在这个场子里能拿到的份额上限就是 ≈13%。**

> 这决定了行动顺序：**先动 V，再动产品。**
> V 是确定的、可算的、不依赖猜测的杠杆；
> 产品改版是在需求未明时押注——可能改对，也可能把一个本来只是份额问题的项目，重做成产品问题。

## 三、四条结构性归因：为什么体感是"不如其他明星"

### 归因 A（最锋利）：客单价被压到了六分之一

同一批客流，不同主体的客单价差 2-6 倍：

| 货架 | 实际单价 | 客单价带 |
|---|---|---|
| **鸟巢限定系列** | 铝杯 ¥28 / 鸟巢水 ¥3 / 折扇 ¥45 / 磁吸手机支架 ¥45 / 旋转气囊支架 ¥49 / 流麻亚克力冰箱贴 ¥68 / 贴贴乐磁石章 ¥128（限量2026套） | **¥3-128** |
| **PHANTACi J CARNIVAL II** | Tumbler ¥160.77 / TEE ¥262-303 / Beanie ¥262 / Cap ¥344 / 卫衣 ¥507-549 / 长裤 ¥507 / 短裤 ¥610 / 外套 ¥672 / Disney 联名 TEE ¥344 | **¥262-672** |
| **ETERSOURCE 收藏卡** | ¥350/盒，5张/包×10包/盒，**全球限量 118,000 盒** | **¥350**（且高复购） |

**粗算**（推算，非实测）：19.5 万人次、按 20% 转化 = 3.9 万购买人次
- 按鸟巢限定结构（均值估 ¥60）→ 约 **¥234 万**
- 按 PHANTACi/收藏卡结构（客单估 ¥400）→ 约 **¥1,560 万**
- **相差约 6.7 倍，而观众人数完全相同。**

> **结论：差距不在"有多少人买"，在"买到多少钱"。**
> CMIS 针对这场给出的建议客单价是「单品 ¥150-400、礼盒 ¥600-1500」（见 v5.4 全案第 3 章）。
> 实际货架**完全没有这两个价格带**——中间带与礼盒带双双空缺。

而且隐藏了两条"钱流向别处"的通道：
一、**ETERSOURCE 收藏卡 ¥350×11.8 万盒 ≈ ¥4.13 亿 GMV 上限**，由 JVR Music 授权、巨星传奇作全球总代理，
**走的完全是另一条通道**（商场贩售机、周同学门店、全国商城）。这块的钱，不在场内任何一个摊位的收银机里。
二、钥匙扣二级**挂价** ¥399（未见成交证据）——若属实，说明一级定价确实过低，
但**这条只能作为"值得核查"的线索，不能作为已证实的结论**（v6.2 降级处理）。

### 归因 B：位置份额被 6 家分光

现场 6 个并行主体，即使完全均分，**单点结构性上限也只有 1/6 ≈ 17%**。
再按品牌力加权——PHANTACi 是周杰伦本人的品牌、周同学是上市公司主理 IP——第三方/场馆联名款拿到的份额只会更低。

### 归因 C：时间窗口被拉长 8 倍

「寻找周同学·龙耀鸟巢」全域文旅活动：6 月中旬启幕，**持续至 7 月 8 日**。
演唱会是 6/26-28。
叠加：全城 **12 处地标**、**6 大商场**巨型大娃 + 北京限定形象及周边（水立方 / 北辰荟 / 富力广场 / 金融街购物中心 / 隆福寺 / 首钢园）、高德 App 专属护照集满 6 章领礼、主题餐厅、长期店。

**场馆内、演出日的销售窗口 ≈ 3 天 / 全域活动 23 天 ≈ 13%。**

> 这冲击了 CMIS 一个从未被质疑的默认假设：**"演唱会文创的销售窗口 = 演出当天 × 场馆内"。**
> 对强 IP，窗口是"全城 × 全月 × 全渠道"。这不是特例，这是 IP 成熟到一定程度后的必然形态。

### 归因 D：品类已被 200+ 家既有授权占满

- 「周同学」自 2019 年推出，已授权 **200+ 家**，覆盖时尚 / 文创 / 3C / 食品 / 贵金属，**累计联名销售额超 10 亿元**
- 2025 年进入上海博物馆，成为首个进入国家级博物馆的明星 IP
- **2025-09 巨星传奇收购鸟巢运营公司约 1.17% 股权，成为鸟巢唯一民营企业股东**
- 巨星传奇同时**参与投资/策划《嘉年华》世界巡回演唱会**

> 这意味着：一个第三方能想到的几乎所有品类，**都已有常年被授权方在全年售卖**。
> 限定款的全部价值来自稀缺性；当同 IP 同品类在天猫/门店常年有售，**限定就不再是限定**。

### 归因 E（次要）：历史信任损伤

成都站曾出现「地表最强纪念衫两件 + 成都站购票权 ¥560」「保证有票」「不退不换」的捆绑销售，被网友称为**"官方黄牛"**。
这类事件会长期抬高粉丝对官方周边的价格敏感度与道德反感，压低 `w` 的心理上限。

### 归因 F（次要）：促销密度暴露动销冷热不均

同场同时挂着三档促销：铝杯**买1赠1**、免费无限续杯、**满¥29 赠五彩绳盲袋**（且不含铝杯与鸟巢水）。
这类促销组合通常出现在"低单价件需要拉动"的场景。

> **注意：这条是"冷热不均"的线索，但它同时也是一个反向信号——**
> 需要促销拉动的恰恰是主力货架（铝杯/水），这与"全场供不应求"的说法**互相矛盾**。
> v6.1 只采信了哄抢那一半，忽略了促销这一半。**证据撤销后，这一半反而成了更该看的一手信息。**

### 归因 G（v6.2 新增）：现场损耗

6/27 暴雨那晚被成包取走的毛毯与玩偶，**在会计上是库存流失，不是销售**。
这类损失此前从未进入 CMIS 的备货模型——**货会在现场以非销售方式消失**。

已据此在 `supply-chain.md` §三·B 新增**现场损耗率 δ**：

| 场景 | δ |
|---|:---:|
| 室内剧场、有围栏与收银动线 | 0.5-1% |
| 体育场环廊摊位、散场高峰 | 2-3% |
| **露天/半露天 + 恶劣天气** | **5-8%** |

> 高单价软性商品（毛毯/玩偶/服饰）**不得堆放在开放动线上**——它们是哄抢时的首选目标。
> 恶劣天气预案必须包含"**暂停售卖 + 收拢货品**"，而不是只加雨棚。

## 四、对"授权延误"这条旧记录的修正（重要）

CMIS v5.3 曾记录："周杰伦案核心原因是经纪公司 IP 管理混乱，临近演出仍未敲定方案。"
这条**观测是真的，归因写错了**。

正确因果：

```
现象：第三方拿不到及时授权
  ↑ 不是因为 没人负责
  ↑ 而是因为 队列太长：PHANTACi（自有潮牌）/ 巨星传奇（IP 版权方）
      / 环球音乐（唱片方）/ 方文山（创作方）/ JayMe（社区）/ 场馆（鸟巢自有文创）
      六方都已在位，且巨星传奇同时是投资人、IP 版权方、鸟巢股东
结论：延误是结果，不是原因。真正的原因是"权利人密集"。
```

> 这个修正改变了处方：
> 旧的处方是"早点催、早点签"；
> 正确的处方是"**进场前先算清楚你在这条队列里排第几，以及你被允许卖什么品类**"。
> 排位靠后还按常规零售预期报价，必然亏。

## 五、结论：正确的表述应该是这样

| 说法 | 判定 | 依据 |
|---|---|---|
| "周杰伦周边卖不动" | **◐ 无法证实** | 周边侧**无一级需求证据**。v6.1 曾用"哄抢"证伪，该证据已撤销 |
| "周边供不应求、备货不足" | **❌ 撤销** | 唯一支撑（6/27 哄抢）是治安事件，非交易性流失；且主力货架挂着买1赠1促销，与"供不应求"矛盾 |
| "经纪公司审美有问题" | **◐ 无法证实** | 审美问题表现为不动销，而我们没有不动销的证据。**准确说法是"无证据"，不是"已证伪"** |
| "管理混乱阻断了产品环节" | ❌ **不成立** | 现场六级主体 + 统一编号 + 统一自提核销 + 统一售后，组织度极高。**不受撤销影响** |
| "**单点可捕获流水结构性低于同等票房的艺人**" | ✅ **成立（本案主结论）** | 客单 ¥3-128 vs 同场 ¥262-672；6 家分食；13% 时间窗；品类被 200+ 授权占满 → **V≈0.13** |
| "**钱主要流向了别的通道**" | ✅ **成立** | ETERSOURCE 收藏卡 ¥350×11.8 万盒走场外；PHANTACi 客单价高 4-5 倍 |

> **一句话给业务侧（v6.2 版）：**
> 我们**目前无法证明周边卖得好还是不好**——因为缺少成交数据。
> 但有一件事**不需要任何销量数据就能确定**：**在这个场子里，一个单点能拿到的份额上限约 13%。**
> 所以优先动的是**商业模式与客单价结构**，而不是产品本身。
>
> **要真正定性，只需要一个数：我方 POS 的成交售罄率。** 拿到它，① 就能被证实或排除。

## 六、对 CMIS 的升级要求

本案暴露了模型的一处结构性缺失：**CMIS 此前只有"需求侧能不能卖"（w/s/λ/f）和"供给侧来不来得及"（授权/工期），没有"这场赚的钱有多少归我"。**

升级清单（v6.1 已交付）：

1. **新增「卖得不好」四类口径核对**（`value-capture.md`）
   先判 ①卖不动 / ②不够卖 / ③没份额 / ④归别人，再开处方。
2. **新增价值捕获率 V**（四个分量 V_pos / V_price / V_window / V_category）
3. **τ 扩为双向**：成熟 IP（>3年 且 授权商>50家）进入"品类饱和态"，常规限定失效
4. **f 扩为双向**：饱和端提供反向修正
