# 周杰伦「龙拳·北京·嘉年华2026」鸟巢站
## 周边表现专业评估 —— 兼论"顶流卖不动"这个说法错在哪

> 评估日期：2026-10-31｜CMIS v6.1 归因样本
> 结论先行：**"周杰伦鸟巢周边卖得不好"这个说法，口径就是错的。**
>
> 现场发生了两件同时为真的事实：
> **① 6月27日暴雨，官方周边遭哄抢，多个销售点被"洗劫一空"，奥林匹克公园派出所介入调查；**
> **② 同场布设了 6 个官方售卖体系，配统一点位编号、统一自提核销规则、统一售后条款。**
>
> 一个被抢空的市场，不能叫"卖不动"；一个能排出六级主体的体系，不能叫"管理混乱"。
> 真正低的是**"我方（定制款/单点）所能捕获的流水"**，而不是这个项目本身的需求。

| ❌ "管理混乱把产品环节阻断了" | 混乱的组织排不出下面这张六级售卖体系表 |

## 二、真正发生了什么：现场是一个高度有序的"六级售卖体系"

鸟巢零层、一层、二层、五层布设的官方周边点位，共 **6 个并行主体**：

| # | 主体 | 归属 | 性质 |
|---|------|------|------|
| 1 | **PHANTACi** | 周杰伦 2006 年与 Ric Chiang 创立、本人任创意总监的**自有潮牌** | 艺人自有零售体系 |
| 2 | **周同学 CHOUCHOU&FRIENDS** | 巨星传奇（港股 6683），周同学 IP 版权方 | 上市公司 IP 官方店 |
| 3 | **JayMe** | 官方粉丝社区 | 会员体系 |
| 4 | **环球音乐唱片·享乐派** | 唱片公司 | 唱片方渠道 |
| 5 | **方道文山流 by 方文山** | 作词人自有品牌 | 创作伙伴个人 IP |
| 6 | **周同学 × 鸟巢限定系列** | 场馆 × IP 联名 | 场馆联名款 |

场馆外与线上另有四条通道：
- 鸟巢一层基座 MA/BC/CD/EF/FG 五个点位，**周同学快闪店**（营业至 6/29，非演出日 10:00-21:30）
- 奥林匹克公园北中轴景观大道旁，**CHOUCHOU&FRIENDS 长期店**
- 微信小程序「巢极购」预售 + 7 个自提点 + 快递（部分品仅支持快递）
- 周同学鸟巢限定**主题餐厅**（6/19-6/29）

配套规范：统一楼层方位/临近柱号/点位编号的自提表、统一的离开售卖区不售后条款、统一的限量款随机流水号规则、统一的兑换逻辑。

> **这不是"没人管"，是"管得很好，而且已经排满了"。**
> 一个第三方想要进场，面对的不是混乱，是**一条已经很长的队列**。

## 三、四条结构性归因：为什么体感是"不如其他明星"

### 归因 A（最锋利）：客单价被压到了六分之一

同一批客流，不同主体的客单价差 2-6 倍：

| 货架 | 实际单价 | 客单价带 |
|---|---|---|
| **鸟巢限定系列** | 铝杯 ¥28 / 鸟巢水 ¥3 / 折扇 ¥45 / 磁吸手机支架 ¥45 / 旋转气囊支架 ¥49 / 流麻亚克力冰箱贴 ¥68 / 贴贴乐磁石章 ¥128（限量2026套） | **¥3-128** |
| **PHANTACi J CARNIVAL II** | Tumbler ¥160.77 / TEE ¥262-303 / Beanie ¥262 / Cap ¥344 / 卫衣 ¥507-549 / 长裤 ¥507 / 短裤 ¥610 / 外套 ¥672 / Disney 联名 TEE ¥344 | **¥262-672** |
| **ETERSOURCE 收藏卡** | ¥350/盒，5张/包×10包/盒，**全球限量 118,000 盒** | **¥350**（且高复购） |

**粗算**（推算，非实测）：19.5 万人次、按 20% 转化 = 3.9 万购买人次
- 按鸟巢限定结构（均值估 ¥60）→ 约 **¥234 万**
- 按 PHANTACi/收藏卡结构（客单估 ¥400）→ 约 **¥1,560 万**
- **相差约 6.7 倍，而观众人数完全相同。**

> **结论：差距不在"有多少人买"，在"买到多少钱"。**
> CMIS 针对这场给出的建议客单价是「单品 ¥150-400、礼盒 ¥600-1500」（见 v5.4 全案第 3 章）。
> 实际货架**完全没有这两个价格带**——中间带与礼盒带双双空缺。

而且隐藏了一个反向信号：结构里有 double loss。
一、**一级定价过低 → 价值被二级市场吃掉**（钥匙扣原价几十，黄牛 ¥399）。
二、**ETERSOURCE 收藏卡 ¥350×11.8 万盒 ≈ ¥4.13 亿 GMV 上限**，由 JVR Music 授权、巨星传奇作全球总代理，**走的完全是另一条通道**（商场贩售机、周同学门店、全国商城）。
这块的钱，不在场内任何一个摊位的收银机里。

### 归因 B：位置份额被 6 家分光

现场 6 个并行主体，即使完全均分，**单点结构性上限也只有 1/6 ≈ 17%**。
再按品牌力加权——PHANTACi 是周杰伦本人的品牌、周同学是上市公司主理 IP——第三方/场馆联名款拿到的份额只会更低。

### 归因 C：时间窗口被拉长 8 倍

「寻找周同学·龙耀鸟巢」全域文旅活动：6 月中旬启幕，**持续至 7 月 8 日**。
演唱会是 6/26-28。
叠加：全城 **12 处地标**、**6 大商场**巨型大娃 + 北京限定形象及周边（水立方 / 北辰荟 / 富力广场 / 金融街购物中心 / 隆福寺 / 首钢园）、高德 App 专属护照集满 6 章领礼、主题餐厅、长期店。

**场馆内、演出日的销售窗口 ≈ 3 天 / 全域活动 23 天 ≈ 13%。**

> 这冲击了 CMIS 一个从未被质疑的默认假设：**"演唱会文创的销售窗口 = 演出当天 × 场馆内"。**
> 对强 IP，窗口是"全城 × 全月 × 全渠道"。这不是特例，这是 IP 成熟到一定程度后的必然形态。

### 归因 D：品类已被 200+ 家既有授权占满

- 「周同学」自 2019 年推出，已授权 **200+ 家**，覆盖时尚 / 文创 / 3C / 食品 / 贵金属，**累计联名销售额超 10 亿元**
- 2025 年进入上海博物馆，成为首个进入国家级博物馆的明星 IP
- **2025-09 巨星传奇收购鸟巢运营公司约 1.17% 股权，成为鸟巢唯一民营企业股东**
- 巨星传奇同时**参与投资/策划《嘉年华》世界巡回演唱会**

> 这意味着：一个第三方能想到的几乎所有品类，**都已有常年被授权方在全年售卖**。
> 限定款的全部价值来自稀缺性；当同 IP 同品类在天猫/门店常年有售，**限定就不再是限定**。

### 归因 E（次要）：历史信任损伤

成都站曾出现「地表最强纪念衫两件 + 成都站购票权 ¥560」「保证有票」「不退不换」的捆绑销售，被网友称为**"官方黄牛"**。
这类事件会长期抬高粉丝对官方周边的价格敏感度与道德反感，压低 `w` 的心理上限。

### 归因 F（次要）：促销密度暴露动销冷热不均

同场同时挂着三档促销：铝杯**买1赠1**、免费无限续杯、**满¥29 赠五彩绳盲袋**（且不含 albumin铝杯与鸟巢水）。
这类促销组合通常出现在"低单价件需要拉动"的场景；而 6/27 被抢空的恰恰是**毛毯、玩偶**这类高感知物件。

> **同一场里，一部分 SKU 需要促销拉动，另一部分被抢空。** 这是结构冷热不均，不是整体好或整体差。

## 四、对"授权延误"这条旧记录的修正（重要）

CMIS v5.3 曾记录："周杰伦案核心原因是经纪公司 IP 管理混乱，临近演出仍未敲定方案。"
这条**观测是真的，归因写错了**。

正确因果：

```
现象：第三方拿不到及时授权
  ↑ 不是因为 没人负责
  ↑ 而是因为 队列太长：PHANTACi（自有潮牌）/ 巨星传奇（IP 版权方）
      / 环球音乐（唱片方）/ 方文山（创作方）/ JayMe（社区）/ 场馆（鸟巢自有文创）
      六方都已在位，且巨星传奇同时是投资人、IP 版权方、鸟巢股东
结论：延误是结果，不是原因。真正的原因是"权利人密集"。
```

> 这个修正改变了处方：
> 旧的处方是"早点催、早点签"；
> 正确的处方是"**进场前先算清楚你在这条队列里排第几，以及你被允许卖什么品类**"。
> 排位靠后还按常规零售预期报价，必然亏。

## 五、结论：正确的表述应该是这样

| 说法 | 判定 | 依据 |
|---|---|---|
| "周杰伦周边卖不动" | ❌ **错误** | 6/27 哄抢、多点被抢空、派出所介入、二级溢价 ¥399 |
| "经纪公司审美有问题" | ❌ **不成立** | 审美问题表现为不动销，不表现为抢购失控 |
| "管理混乱阻断了产品环节" | ❌ **不成立** | 现场六级主体 + 统一编号 + 统一自提核销 + 统一售后，组织度极高 |
| "**单点可捕获流水低于同等票房的艺人**" | ✅ **成立** | 客单被压到 ¥3-128（同场 PHANTACi ¥262-672）；6 家分食；13% 时间窗；品类被 200+ 授权占满 |
| "**本案是供给不足 + 价值捕获不足的混合型**" | ✅ **成立** | 抢空说明备货不足；多主体多渠道说明钱流向了别处 |

> **一句话给业务侧：**
> 这不是一个"做出来卖不掉"的项目，而是一个"**需求真实存在、但既没备够货、也没拿到足够份额、份额里的东西又卖得太便宜**"的项目。
> 三种病，处方完全不同。

## 六、对 CMIS 的升级要求

本案暴露了模型的一处结构性缺失：**CMIS 此前只有"需求侧能不能卖"（w/s/λ/f）和"供给侧来不来得及"（授权/工期），没有"这场赚的钱有多少归我"。**

升级清单（v6.1）：

1. **新增「卖得不好」四类口径核对**（`value-capture.md`）
   先判 ①卖不动 / ②不够卖 / ③没份额 / ④归别人，再开处方。本案属于 ②③④ 混合，被误判为 ①。
2. **新增价值捕获率 V**（四个分量 V_pos / V_price / V_window / V_category）
3. **τ 扩为双向**：成熟 IP（>3年 且 授权商>50家）进入"品类饱和态"，常规限定失效
4. **f 扩为双向**：饱和端 f≥1.3 提供反向修正
5. **偏差归因四源 → 五源**：新增"价值捕获源"
6. **修正** `artist-ip-ecosystem.md` 案例4 与 `agency-authorization.md` 的错误归因
