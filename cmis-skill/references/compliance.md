# 合规与风险否决清单

> 用途：在产品定稿前，把"会上不了架/带不进场的产品"提前挑出来。
> 读取时机：Layer 6，逐SKU过一遍；策划书第 14 章直接引用本清单结论。
>
> 免责说明：以下为行业通行经验与常见政策口径，**具体以场馆最新公告、主办方合同、当地监管要求为准**。CMIS 的角色是提示风险与替代方案，不是法律意见。

---

## 一、六条一票否决线（任一为红，该SKU必须改或删）

| # | 否决线 | 典型踩线产品 | 后果 |
|---|-------|------------|------|
| 1 | **安检不允许带入/带出** | 激光笔、强光手电、充气棒、超规格旗杆、含压缩气体的喷雾、仿真武器造型 | 观众买了带不进去，现场退款与舆情 |
| 2 | **电池/电子件不合规** | 无合规电芯的LED棒、可拆卸锂电池、大容量充电宝类 | 物流拒运、安检收缴、起火风险 |
| 3 | **未获授权的IP/肖像/录音** | 艺人照片印刷、影视剧照、歌词全文、演唱会现场录音波形 | 侵权索赔、全部下架 |
| 4 | **未获授权的场馆/城市标志** | 鸟巢建筑形象与"鸟巢"字样、奥运五环、城市标志性雕塑形象 | 场馆方与权利人异议，整批扣货 |
| 5 | **食品/化妆品/儿童用品缺资质** | 联名食品、饮品、香氛、儿童玩具 | 无证销售、监管处罚 |
| 6 | **虚假或无法证明的宣传表述** | "国家级""最""唯一""限量"但实际可无限补货 | 广告法风险、粉丝反噬 |

## 二、分类细则

### A. 场馆安检（影响最大的单一变量）

| 品类 | 常见限制 | 应对 |
|------|---------|------|
| LED应援棒/发光件 | 部分场馆限制"长杆、可投掷、强光、可拆卸电池"；有的要求统一使用主办方场控棒 | ①提前取得场馆/主办书面确认 ②做短款、内置不可拆卸电池、光强限值 ③备"无灯版"作为替代SKU |
| 充气棒/气球 | 多数场馆禁止充气物入场（易遮挡、易燃） | 改为布艺/纸质应援物；或仅作场外使用并明确标注 |
| 旗杆/横幅 | 长度与材质受限 | 改为手持小旗、头巾、贴纸 |
| 激光类 | 基本全禁（伤眼、干扰演出） | 直接删除该功能 |
| 液体/喷雾（含香水、彩带喷雾） | 限带或禁带 | 改为固体香膏、纸质彩带 |
| 硬质/尖锐件 | 金属尖角、可作投掷物 | 圆角处理、软胶包边 |

> **必做动作**：在方案中写明"安检确认责任人 + 确认截止日（不晚于 T-20）"，并准备 Plan B 替代品。谢霆锋案中"LED挂件取决于安检通过"就是典型的未闭合风险。

### B. 电池与电子件

- 优先**内置不可拆卸电池**（避免观众拆装、避免被视为"电池类危险品"）
- 锂电池运输需陆运，跨省配货时间 +3-5 天；空运需鉴定报告
- 电子件必须做**老化测试与跌落测试**，并留 1-2% 备品
- 场控/联动方案需与主办方技术团队提前联调（不是自己测通就行）

### C. 版权

| 对象 | 是否需要授权 | 说明 |
|------|------------|------|
| 艺人姓名/艺名 | 需（商标+姓名权） | 通常由经纪公司在合同中授权范围 |
| 艺人肖像/照片 | 需 | 粉丝普遍排斥"印大头照"，且授权成本高，多数情况直接规避 |
| 歌词 | 需（音乐著作权） | 短句/歌名相对安全，成段歌词必须授权；建议控制在 1 句以内并标注出处 |
| 曲名/专辑名 | 通常需 | 作为"作品名称"使用仍建议报备 |
| 录音/声纹波形 | 需（录音制作者权） | 声纹暗纹看似抽象，仍属录音制品衍生，需授权或用现场授权素材 |
| 舞美/主视觉 | 需（设计方著作权） | 巡演视觉通常归主办/设计公司，不能直接搬用 |
| 场馆建筑形象 | 需（场馆方） | 鸟巢的图形、名称、轮廓均需授权；"隐性层"用法也建议书面确认 |

> 实操建议：把"版权清单"作为设计交付的一部分——**每个视觉元素标注来源与授权状态（已授权/待授权/规避）**，没有标注的不进排版。

### D. 场馆与城市IP

- 场馆名称/简称/建筑轮廓：需场馆方授权，联名合作通常写入合同
- 城市标志物（熊猫、地标雕塑等）：部分属公有，部分有管理方，商业使用需确认
- 奥运相关元素（五环、吉祥物、口号）：**绝对禁用**，除非有正式授权

### E. 广告与宣传

| 禁用/慎用 | 替代写法 |
|----------|---------|
| "国家级""最高级""最佳" | 删除或改为可验证描述 |
| "绝版""唯一" | 需与限量数一致，且承诺不再版 |
| "限量XXXX件" | 必须真实可核；编号体系要能对账 |
| "官方正版" | 需有授权文件支撑 |
| 价格比较（"原价¥599"） | 需有真实成交记录依据 |

### F. 预售与售后

- 演后发货必须写明：**发货时间、物流方式、退换规则、超时赔付**
- 预售不得虚假承诺"演出前送达"
- 现场销售需取得主办方/场馆的销售许可与摊位授权（含分成条款）
- 收款需能开发票；个体摊位也要保留销售凭证

## 三、SKU 定稿前逐项确认（每个SKU打勾）

- [ ] 安检可通过（或已有替代方案与责任人）
- [ ] 电池/电子件合规，物流方式确认
- [ ] 所有视觉元素有授权状态标注
- [ ] 无奥运/赛事标志、无未授权场馆图形
- [ ] 宣传文案无极限词，限量数真实可查
- [ ] 儿童可接触件无小零件风险（如有儿童向设计）
- [ ] 食品/化妆品类有资质（如涉及）
- [ ] 退换与发货规则已写入销售页
