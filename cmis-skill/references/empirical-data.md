## 核心规律提炼

### 规律1：高差异化产品有共同的设计路径

所有爆款/高差异化产品，都遵循同一个逻辑：

```
从艺人专属符号出发 → 寻找最适合该符号的产品形态 → 确定品类
```

而非：
```
先定品类（T恤/钥匙扣）→ 往里填艺人元素
```

### 规律2：差异化产品类型分布

| 类型 | 典型案例 | 适用条件 |
|------|---------|---------|
| IP符号异形产品化 | 五球拼图冰箱贴、磁带钥匙扣、龙拳大娃棒 | 艺人有具体可视化符号/形象 |
| 情绪互动体验产品 | NFC冰箱贴、发声罐、旋转磁石章 | 演唱会有强情绪主题（快乐/陪伴/治愈） |
| 篇章符号毛绒/玩偶化 | 八花毛绒挂件、Q版怪物钥匙扣 | 演唱会有专属视觉形象 |
| 工艺差异化 | 光栅小卡、刺绣棒球帽、镂空纪念币 | 图案本身无法差异化时，用工艺拉开距离 |
| 功能+IP二合一 | 龙拳大娃场控荧光棒 | 应援功能品可做IP造型化 |
| 极端定价收藏品 | ¥499 LIVE实体CD、限量2026套磁石章 | 适合粉丝忠诚度极高的艺人 |

### 规律3：谢霆锋案例的量化验证

谢霆锋产品矩阵中差异化产品占比最低（~22%），整体销量规模明显低于同期其他艺人，且「锋味联名纪念币」（差异化程度最高的单品）销量反而是所有SKU中最低的。这同时印证了两个结论：
1. 分流率高 → 演唱会限定款整体吸引力下降
2. 自有品牌联名款 ≠ 一定能带来销量（如果粉丝感知为"锋味又出东西了"而非"演唱会限定独家"）

## 特殊案例（非典型偏差，v5.3 新增）

> 这三个案例的共同点：**都不符合"艺人越红、周边越好卖"的直觉**。
> 它们分别对应模型里的三个不同变量，是校准参数时最重要的锚点。

### 案例A：周杰伦 — 流量最大，定制款反而不如其他艺人

| 项目 | 内容 |
|------|------|
| 现象 | 华语顶流，门票溢价极高，数万人到场；但鸟巢定制款伴手礼销售不如其他同量级艺人 |
| 归因（据业务侧反馈） | 经纪公司 **IP 管理与授权链条混乱**，临近演唱会仍未敲定合作方案 → 设计、开模、生产被压缩到不可行区间；实际能上架的品类与数量都被动缩水 |
| 影响变量 | 不是 `w`、不是 `s`，而是**"能不能开始做"**——组织与授权可行性 |
| 已写入 | `artist-ip-ecosystem.md` 组织与授权评估；`supply-chain.md` 授权倒排；Gate A 合作确定性 |
| 待补 | 授权延误天数、实际上架 SKU 数与原计划的差异、因此损失的流水 |
| 教训 | 流量再大，也补不回被授权拖掉的 45 天 |

### 案例B：赵雷 — 首个民谣歌手进鸟巢，预测偏低但实际爆

| 项目 | 内容 |
|------|------|
| 现象 | 民谣听众普遍保守、收敛，事前预测周边销售一般；实际**棒球帽、钥匙扣反响极好，连连补货**；演出结束一个月仍有粉丝讨论"戒断反应" |
| 归因（假设） | ①把"不喧哗"错读为"不消费" ②品类结构错配：应援类无效，**日常可佩戴的低调配饰**承接了需求 ③情绪浓度高、复购与多件比例高 ④长尾远长于流行歌手 |
| 影响变量 | `w`（略被低估）+ `s`（严重错配）+ `λ`（严重低估） |
| 已写入 | `artist-archetypes.md` 创作/民谣型参数与结构修正；`quant-model.md` λ 与三误差源 |
| 待补 | 实际销量、首批量与补货次数、演后 30/60 天销量占比、单品售罄曲线 |
| 教训 | 预测偏差的第一来源常常是**结构**和**长尾**，不是总量 |

### 案例C：谢霆锋 — 自带货进场，定制款被同场压制

| 项目 | 内容 |
|------|------|
| 现象 | 大牌艺人，但自带汉堡、饮料、T恤、方巾等产品在场内销售；鸟巢定制款销售平平 |
| 归因 | **同场、同预算、同品类竞争**（分流来源 E）+ 自有品牌长期渠道（来源 A/B/C）叠加 |
| 影响变量 | `k`（需再乘现场修正 0.85-0.90） |
| 数据佐证 | 「锋味联名纪念币」差异化最高，销量却是全部SKU最低（19,000） |
| 已写入 | `artist-ip-ecosystem.md` 分流来源 E；`quant-model.md` 现场修正系数 |
| 待补 | 自有摊位 vs 定制摊位的销售拆分、人均消费结构 |
| 教训 | 调研联名机会时，必须同时盘清**艺人自己带了多少货进场** |

## 品类销量结构占比（v5.2 归一化测算）

> 口径：各艺人内部归一化（该功能组销量 ÷ 该艺人全部SKU销量合计）。用于**结构对标**，不用于绝对值承诺。
> 分组为近似归类（如"磁石章"计入金属收藏、"皮质手环"计入小件配饰），跨组合并已尽量注明。

| 功能组 | 五月天 | 谢霆锋 | 黄子弘凡 | 张杰 | 汪苏泷 | 周杰伦 | 建议取值 |
|--------|-------|-------|---------|------|-------|-------|---------|
| 应援/氛围（棒、套、毛巾） | 30.9% | 24.7% | 11.7% | 35.3% | 18.0% | 21.6% | 12-35% |
| 刚需收纳（票根套、卡套、票夹） | — | 19.5% | — | 8.6% | — | 26.1% | 9-26% |
| 小件挂饰（亚克力、钥匙扣、发绳、挂饰） | 13.4% | 21.6% | 30.4% | 19.5% | 40.3% | 19.8% | 13-40% |
| 异形/IP形象（毛绒、互动件、造型件） | 13.4% | — | 37.5% | 10.5% | — | — | 10-38% |
| 金属收藏（徽章、套组、盲盒、纪念币） | 14.5% | 22.5% | — | 8.9% | — | 16.7% | 9-22% |
| 穿着（T恤、卫衣、外套、帽、袜） | 22.5% | 11.8% | 11.2% | 17.2% | 10.8% | 12.1% | 11-23% |
| 配饰/家居（冰箱贴、水杯、抱枕、毛毯、包袋） | 5.4% | — | 6.9% | — | 28.2% | — | 5-28% |
| 极端收藏（CD、黑胶、礼盒） | — | — | 2.2% | — | 2.5% | 3.7% | 2-4% |

**单品层面参考**：T恤单品份额仅 5-12%（常被误认为"最畅销品类"）；周杰伦磁带钥匙扣单品 19.8%、汪苏泷 Q版钥匙扣 26.1%——符号化单品可以超过服装类。

### 三条可直接用于决策的结论

1. **"小件 + 异形/IP形象"合计常占 25-65%**（黄子弘凡 68%、汪苏泷 60%）：这既是销量底盘，也是差异化唯一能落地的地方。矩阵里如果这一类缺失，等于把销量押在通用品类上。
2. **应援类是最大单类（12-35%），但也是同质化最严重的类（100% 出现率）**：量最大、风险最高，必须在外形/互动机制上做出专属创新，否则就是"换色换logo"。
3. **穿着类占 11-23%，不是走量品类而是毛利与品牌载体**：T恤备货应按 7-10% 份额计算，而非按"最畅销"押注；重工外套类（2-4%）只做小批品牌款。

## 数据口径与局限（务必如实告知客户）

| 项目 | 说明 |
|------|------|
| 数据性质 | 上述销量为**行业预估/推算值**，非结算实际数 |
| 样本 | 6 位艺人、56 个 SKU，均为体育场级场地，不代表中小场馆 |
| 偏差风险 | 预估口径不一，跨艺人绝对值不可直接比较，**只能比结构** |
| 使用边界 | 用于结构对标、份额取值、差异化判断；不得作为销量承诺或投资依据 |

## 回填规则（v5.2 新增，形成复利）

每个项目结束后 30 天内，把实际数据补进本文件，格式：

```
### [艺人] — [演唱会]（[日期]，[场馆]，[场次]）
| 产品 | 售价 | 首批量 | 实际销量 | 售罄率 | 补货次数 | 差异化程度 | 符号来源 | 复盘一句话 |
```

**新增必填四项（v5.3）**：

| 字段 | 用途 |
|------|------|
| 圈层类型 | 校准 `w` / `λ` 的圈层分档 |
| 授权签约日 vs 演出日 | 量化"组织与授权"对结果的影响（周杰伦型问题） |
| 演后 30/60 天销量占比 | 校准 `λ`（赵雷型问题） |
| 自有货进场品类与摊位销售 | 校准现场修正（谢霆锋型问题） |

同时更新：
1. `quant-model.md` 中对应的份额区间、意愿率 w、长尾系数 λ
2. 若某 SKU 偏差 >30%，按 `quant-model.md` 的"三误差源"归因（总量/结构/长尾），并写下"为什么错了"（一句话，必须具体）
3. 同类偏差出现 3 次 → 修改基准表，并在 CHANGELOG 记录

> 没有回填的项目，视为未完成交付——因为下一份方案还会犯同样的错。
