# 符号系统：可物化性 · IP成熟度 · 归属度 · 首次周边化

> 用途：回答一个此前被跳过的前提问题——**这个艺人的情感，能不能被做成一件东西？**
> 读取时机：Layer 1 D1 IP 资产盘点（算 O / τ / f）→ Layer 3 D4 场域叙事（算 α）→ Gate A 与 Gate B（拦截）。
>
> **来源 v6.0**：凤凰传奇「吉祥如意」鸟巢站周边销量远低于预期。
> 16 个 SKU、6 场连开、36 万人次到场、门票 1 分钟售罄，**仍卖不动**。
> 复盘结论不是"粉丝不买"，而是 **没有任何一件商品只能通过"凤凰传奇粉丝"这个身份成立**。
> 完整归因见 `cases/凤凰传奇_吉祥如意鸟巢站_滑铁卢复盘.md`。

---

## 零、为什么需要这一层

旧的 D1「IP 资产缺口表」只会填"有 / 无卡通形象"。它拦不住实际执行中的偏离，因为它缺三样东西：

| 缺什么 | 后果（凤凰传奇案实证） |
|---|---|
| **没有"能不能物化"的判断** | 只看"有/无 IP 形象"，没识别出资人资产是**听觉与集体行为**，本质上不可物化 |
| **没有"IP 多久了"的量化** | "丢丢是新 IP"停留在定性，无法拦住"新 IP 就上多角色盲盒"这种最高难度组合 |
| **没有"符号归谁"的归属判断** | "凤归巢""2026 收官"这些叙事一路绿灯走进行李牌，没人问过它在粉丝心里属于谁 |
| **没有"第一次做"的折价** | 粉丝脑中不存在"凤凰传奇官方周边"这个品类，却被按成熟市场算了意愿率 |

四个变量一起进模型，才能把这类"人来了、票抢光了、东西卖不动"的项目在立项阶段就识别出来。

## 一、O｜符号可物化性（Objectifiability）

### 定义

> **核心符号能否脱离声音与时间，被画出来、被独立认出、被持在手里。**

评分三问，各占一票（答"是"得 1 分，满分 3 分换算）：

| # | 提问 | 检验方法 |
|---|---|---|
| ① | 这个符号**能被画出来**并被目标人群认出吗？ | 拿一张只有图形、没有文字的图给粉丝看，能否认出 |
| ② | 它**是否已经出现在粉丝自发内容里**（二创、表情包、梗图、手绘）？ | 社媒检索：有没有人**主动**画它 |
| ③ | 它**能脱离声音/时间独立存在**吗？ | 关掉声音、静止不动，这个符号还在不在 |

```
O = (① + ② + ③) / 3        ← 各问按 0/0.5/1 计
```

> 第 ③ 问是关键否决位：**声音锚定型符号（旋律、人声、合唱）天然得 0 分。**

### 分档与操作

| O | 档位 | 代表 | 能做什么 | **禁止做什么** |
|---|---|---|---|---|
| **0.7-1.0** | 高 | 五月天五球、张杰八花、汪苏泷 Q版怪物、周同学 | 直接做符号型 SKU：拼图、毛绒、造型件、盲盒家族 | — |
| **0.4-0.7** | 中 | 磁带类时代符号、单人创作歌手的专辑视觉图形、长期使用的道具/图腾 | 靠**工艺与机制**补位：光栅、NFC、刺绣、发光 | 禁止直接做"印图案"的平价件 |
| **<0.4** | **低** | **凤凰传奇**、纯唱将型、纯 Livehouse 型 | **声音/文本/参与三条路**（见下） | 🔴 **禁止 IP 形象类、娃类、多角色盲盒、角色家族** |

### O < 0.4 的三条唯一可走路（重要）

符号不可物化 ≠ 不能做周边。只是路径完全不同：

| 路径 | 做法 | 为什么成立 |
|---|---|---|
| **① 声音实体化** | NFC 发声卡（15 秒现场声/歌词）、现场录音明信片、发声冰箱贴、可编程旋律盒 | **直接把真实资产做进产品**，绕开"画不出来"的问题。这是传唱型的唯一正解 |
| **② 行为凭证化** | 票根套 + 场次号码、"第 N 名到场"编号、打卡印章、日期压印、合影框道具 | 传唱型粉丝的身份表达方式是**参与了这件事**，那就把"我到场了"做成凭证 |
| **③ 歌词文本化** | 大字报歌词排版、光栅歌词卡、歌词纸条、可撕式歌词贴 | 歌词是他们少数能引用的、可持有文本资产 |

> 一句话：**O 低 → 别做"形象"，做"证据"。**
> 形象会掉进"贴 logo 的通用商品"，而证据无法被通用商品替代。

## 二、τ｜IP 成熟度（Tenure）

### 定义

```
τ = IP 首次公开发布日 → 演出日 的天数
```

> 发布日口径：**正式对外公布**的那一天（发布会/舞台首秀/官宣微博），不是内测或内部设计日。

### 分档

| τ | 阶段 | 可做 | **禁止** |
|---|---|---|---|
| **<180 天** | 认知未建立 | 单形象 **+ 实用功能**（印在杯子/袋/帽上做点缀，不承担主推） | 🔴 **娃类 / 多角色盲盒 / 系列家族** |
| **180-540 天** | 认知形成中 | 单角色延伸（挂件、毛绒单款、亚克力立牌） | 🔴 多角色系列化、隐藏款机制 |
| **>540 天** | 认知稳定 | 家族化、盲盒、多角色、隐藏款、跨品类授权 | — |

### 上调规则（唯一例外）

> τ <180 天，但已跨过 **≥2 个内容爆发节点**（出圈热搜 / 爆款二创 / 知名联名 / 单条百万级种草），**可上调一档**。

判定要严：判断标准是这个 IP **自己**火了，还是**艺人**火了——
"丢丢玩偶卡在楼梯上"的视频走红，红的是玩偶服事故，不是 IP 形象本身，**不算**。

### τ 是双向的：另一端是"过度商业化"（v6.1）

> v6.0 只处理了"太新"。周杰伦案证明，另一端同样致命。

```
饱和态判定：τ > 3 年  且  已授权第三方 ≥ 50 家
```

触发后，覆盖三个后果：

| 后果 | 表现（周同学实证） | 后果等级 |
|---|---|---|
| **① 品类剩余率坍塌** | 2019 年至今授权 **200+ 家**，覆盖时尚/文创/3C/食品/贵金属，累计联名销售额 **>10 亿** | **V_category 直接压到 0.3-0.5** |
| **② 限定性被常年供给抹平** | 粉丝想买的东西，天猫/门店/贩售机全年都能买到 | "演唱会限定"失去稀缺溢价 |
| **③ 权利人密集 → 第三方排队** | PHANTACi / 巨星传奇 / 环球音乐 / 方文山 / JayMe / 场馆六方在位 | 见 `value-capture.md` V_pos |

**饱和态下唯一的三种活法**（常规限定款一律无效）：

| 活法 | 做法 | 难度 |
|---|---|---|
| **独占时间窗** | 拿下"演前 7 天至演后 30 天"的独占销售期，其他授权方在此期间禁售该品类 | 高 |
| **独占品类条款** | 合同写死"本品类在本场次为排他授权" | 高，但必须争 |
| **独占编号稀缺** | 限量编号 + 场次流水号 + 官方验真，制造常年版无法提供的东西 | **中，最易落地** |

> 判定信号：检索"[艺人名] + 授权 / 联名 / IP 形象 + 已合作"。
> 出现"XX 家授权商""累计销售额 X 亿""已进入 X 行业"，**一律按饱和态处理**。

### 为什么盲盒是最高难度

盲盒要求粉丝能**认出并想要多个角色**。这是把 IP 认知的门槛抬到最高：

| 品类 | 对 IP 认知的要求 |
|---|---|
| 印 LOGO 的 T 恤 | 低（认艺人就行） |
| 单角色毛绒/挂件 | 中（认一个形象） |
| **多角色盲盒 + 隐藏款** | **极高（要认全家族，且为随机性买单）** |
| 角色家族联名 | 极高 |

> **Gate A 新增条款（硬约束）**：`O < 0.4` **且** `τ < 180 天` → 形象类/娃类/盲盒**全部不得进入 SKU 矩阵**，
> 无论经纪方如何坚持。这是凤凰传奇案用 ¥16 个 SKU 换来的规则。

## 三、α｜符号归属度（Symbol Ownership）

### 定义

> **这个符号在粉丝认知中，属于艺人自身的程度。**

符号的有效吸引力 = 基础吸引力 × α。

### 三档取值

| 档 | α | 定义 | 例子 |
|---|---|---|---|
| **L3 原生** | 0.9-1.0 | 艺人自己创造、长期使用、粉丝公认属于他 | 歌词、经典曲目视觉、原创图腾（需已沉淀）、五月天五球、张杰八花、《海底》那句歌词 |
| **L2 共有** | 0.4-0.6 | 艺人与场域/城市共同拥有 | 城市叙事（对本地出身艺人）、场馆长期合作形成的绑定 |
| **L1 外部** | 0.1-0.3 | 本质上属于场馆、排期、第三方，只是恰好套得上 | **"凤归巢"（鸟巢有凤凰）**、场馆吉祥物、"2026 最后一场"、"XX 赛事停演"、闭馆前最后一季 |

### 🔴 L1 的负向风险（凤凰传奇案的关键教训）

> α ≤0.3 的符号**不是"效果差"，是"可能为负分"**。

触发负分的条件（满足任一）：

1. 艺人的人设含 **"真诚/不装/反营销/接地气"** 成分
2. 叙事带有**稀缺逼单暗示**（"最后一次""明年就没有了"）
3. 粉丝群体具备**较强的玩梗与反讽能力**（B站/小红书浓度高）

在这三条同时成立时，一个设计精巧的外部叙事会被识别为"营销话术"，**触发的是反感而非购买**。

> 处置规则：**α ≤0.3 的符号默认不使用。** 若经纪方坚持，只允许出现在**礼盒内页一行小字 / 编号卡背面**，
> 并必须通过一句质问："**如果这个叙事不成立，这件产品本身还值得买吗？**" 答不上来 → 删掉这个卖点。

### 一个简明检验

> **艺人自己在公开场合讲过这个故事吗？**
> 讲过 → 至少是 L2。只有策划方在讲 → 一律按 L1 处理。

## 四、f｜首次周边化系数（First-merch Factor）

### 定义

> **粉丝是否已被训练过"买这个艺人的官方周边"这一行为。**

这不是"购买力强不强"的问题，而是**有没有这个行为路径**的问题。
首次做周边 = 粉丝脑中不存在"该艺人官方周边"这个品类，需要一个入口去建立。

### 取值

| 情形 | f |
|---|---|
| 有 ≥2 次成熟周边运作史（近 3 年） | **1.00** |
| 有 1 次，或仅线上小批量试水 | **0.85** |
| **首次做实体周边**（本轮巡演之前无线下周边体系） | **0.60-0.70** |
| 首次 **且** O <0.4（无形象资产） | **0.55-0.65** |
| **饱和态**（v6.1）：常年零售体系成熟、同城/线上随时可买、粉丝持有量已高 | **1.05-1.15，但 V 另算** |

### f 的饱和端（v6.1）

> f 高是好事吗？——**两端都不是火力该落在的地方。**

| 档 | 问题 | 对策 |
|---|---|---|
| **f ≤0.7** | 粉丝**不会**买官方周边（凤凰传奇型）——缺的是行为路径 | 见下方"f 低时的策略调整" |
| **f ≈1.0** | 正常 | 常规处理 |
| **f ≥1.05 且常年零售成熟** | 粉丝**一直在买**，但买的是**常年款**，不是你这批限定 | 见下方三条原则 |

饱和端的关键区别：**没有"说服粉丝买"的问题，只有"为什么现在买、为什么买你这版"的问题。**

**处置三原则**：

1. **不要做认知教育，也不要做引流入门件**——那整套是给 f≤0.7 用的，在饱和端纯属浪费货架
2. **唯一有效的是稀缺与独占**：编号、场次流水号、时间窗独占、品类排他（见 `value-capture.md` §二）
3. **必须同步算 V**——饱和 IP 几乎必然伴随多售卖主体与多条通道。**f 高不等于 V 高**。
   周杰伦案：f≈1.1 而 V≈0.13，典型"火是真火，钱不是你赚"

### f 怎么用（与 k、V 的区别）

`k`（分流率）打折的是**"钱花在别处"**，`f` 打折的是**"根本没有这个消费习惯"**，
`V`（v6.1）打折的是**"赚到了但不在我口袋"**。三者相乘，互不重复。

```
决策人次 D = N × w × k × f
```

### f 低时的策略调整（比数字更重要）

| 调整项 | 做法 |
|---|---|
| **SKU 数下调一档** | L 档按 M 档做（12-16 → 8-11）。首次项目的 KPI 是**建立认知**，不是最大化流水 |
| **必须设入门件** | 至少 1-2 款 **¥15-35** 的低门槛件（贴纸、单枚徽章、小卡）。**这是首次人群唯一的入口**。没有它，整个矩阵失去第一笔转化 |
| **把赠品升级为主推** | 若现场已规划赠品（挂件/亚克力），优先考虑转成正价 ¥35-49 主推款，买赠改为满额赠 |
| **不要打折救场** | f 低的人群问题从来不是价格。打折只会摧毁定位，且无法建立"值得买"的认知 |
| **首批 σ 上调** | f 低意味着预测极不稳定，首批应偏保守（σ +0.05），靠快反补 |
| **写进下一站的资产** | 首次项目的真实产出是"下一站的 f 会变成 0.85"——方案里要明确写出这条复利 |

## 五、四变量汇总表（贴进第 1 章决策摘要）

```
【符号系统四参】 O=0.25（低，声音锚定） | τ=119天（<180，红灯） | α(L1)=0.1-0.3（外部叙事） | f=0.60-0.70（首次）
【拦截结论】 禁止 IP 形象类 / 娃类 / 多角色盲盒；所有场馆与外部叙事只进内页；必设 ¥15-35 入门件；SKU 数下调一档
【代偿路径】 走「声音实体化 + 行为凭证化 + 歌词文本化」三条路，不走形象路
```

## 六、Gate 落点（三条硬闸）

| 闸门 | 新增条款 | 违反后果 |
|---|---|---|
| **Gate A 立项闸** | `O<0.4 且 τ<180` → 形象类/娃类/盲盒**不得入阵** | 退回重做矩阵，不得强行通过 |
| **Gate A 立项闸** | `f ≤0.7` → SKU 数下调一档 + 必设入门件 + 重新报预算 | 上层审批不通过 |
| **Gate B 定量闸** | **可替换性检验**：抹掉艺人名字与 Logo 后仍能照常卖 → 🔴 不得进主推位 | 该 SKU 降为补充款或剔除 |

### 可替换性检验（Substitutability Test）——写在Gate B

> **把产品上所有艺人相关的字（名字、Logo、巡演名）全部抹掉，这件东西还能不能卖？卖给谁？**

- 只能卖给这个艺人的粉丝 → 🟢 真周边，可进主推
- 抹掉后是场馆文创 / 通用服饰 / 无人认识的 IP → 🔴 **不得进主推位**

**正面案例**：周杰伦"磁带造型钥匙扣"抹掉名字还是磁带，但只有粉丝会把磁带当图腾；
五月天"五球拼图冰箱贴"抹掉名字还是五个球，只有五迷认得。这才是周边。

## 七、常见反模式

| 反模式 | 表现 | 为什么错 |
|---|---|---|
| **用 demographic 代替符号判断** | "95 后占六成，所以潮玩盲盒能卖" | 年龄决定不了购买对象。凤凰传奇 66% 是 18-29 岁，盲盒照样不成立 |
| **把"国民度"当"符号强度"** | "十首国民金曲，周边一定好卖" | 国民度在**听觉**里，不在**货架**上。两者不能互换 |
| **策划方叙事当粉丝叙事** | "凤归巢多好的故事" | 粉丝没有接收端；对"不装"人设的艺人还会触发负向反应 |
| **新 IP 上最高难度品类** | τ=119 天就做六角色盲盒 | 同时把认知门槛与机制难度推到顶 |
| **赠品承担最强转化位** | 唯一有转化力的挂件拿去白送 | 把主推位让给了没人买的东西 |
| **全货架无入门件** | 最低价 ¥38，且是非粉丝向的布袋 | 首次周边化人群失去唯一入口 |
