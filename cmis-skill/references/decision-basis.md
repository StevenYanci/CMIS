# CMIS — 决策依据规范（D1-D7 七册）

> 本文件定义方案**前半部**（依据部）的强制内容与验收标准。
> 一句话原则：**没有依据的 SKU 提案，等于拍脑袋。** 依据部不是"背景介绍"，它是后面每一个数字与每一个款式的来源出处。

---

## 0. 三条铁律

1. **顺序铁律**：依据部必须完整出现在 SKU 之前。任何"先给款、再补理由"的写法，一律返工。
2. **含义铁律**：每册结尾必须写 3-5 条「→ 决策含义」，且每条要被第 1 章结论或第 9 章 SKU 真实引用。**没有被引用过的依据，就该删掉**——它不是依据，是凑字数。
3. **诚实铁律**：每册必须有一小节「我们不知道什么」。只写有利信息的依据部，会让后面所有数字虚高。

### 0.1 置信度标注（每个关键数字都必须带）

| 级别 | 含义 | 例 |
|------|------|----|
| **A 可验证** | 官方公告 / 票务页 / 权威媒体 / 平台公开数据 | 鸟巢 6 场、票价 380-1380、B站 78.67% 90/00 后 |
| **B 推断** | 有样本但非全量，或由两个 A 级事实推出 | 跨城观演比例 40-50%、审美权重 |
| **C 假设** | 行业经验值，无本项目数据 | 人均件数 2.1、分成 20% |

> **C 级占比不得超过 30%**。C 级超过 30% 时，方案必须降级为"精简案"，并在第 1 章写明"参数以假设为主，需首场数据校准"。

### 0.2 编号与引用

- 依据条目编号：`D{册号}-{两位序号}`，例：`D2-03 年轻化结构已完成`
- 引用方式：结论后紧跟 `[D2-03]`
- 第 1 章「决策摘要」的每一行结论，必须能追溯到至少 1 个编号；第 9 章每个 SKU 的"符号来源"必须能追溯到至少 1 个编号。
- 兜底：找不到编号的结论，标明「⚠️ 无依据，属判断」——允许存在，但全篇不超过 3 条。

## 2. D1｜艺人档案与 IP 资产

### 2.1 必填字段（12 项，缺一项即为不合格）

| 字段 | 说明 | 常见错误 |
|------|------|---------|
| 主体性质 | 个人 / 组合 / 乐队；组合需注明成员与分工 | 组合当个人写，导致授权与肖像判断全错 |
| 成立/出道时间 | 两个都写（成立≠出道） | 只写出道年，算不出"周年"叙事 |
| 生涯阶段 | 上升期 / 巅峰期 / 稳定期 / 复兴期 / 告别期 | 不判阶段，就无法判断"这是不是历史时刻" |
| 经纪公司 | 公司主体全称 + 与工作室/厂牌的关系 | 把宣传公司当版权方 |
| 唱片/版权归属 | 曲库、录音制品、词曲分别归谁 | 直接引用歌词，未确认词曲授权 |
| 粉丝名称 | 官方称呼 | 用网络俗称写进正式方案 |
| 官方应援色 | 有则给 HEX；**没有就写"无"** | 编一个颜色当应援色 |
| 代表作品 | 5-8 首，标注"国民级/核心/新作" | 罗列 20 首，无法指导设计 |
| 巡演 IP 与本站定位 | 巡演名、第几站、是否首站/收官/生日场 | 用错巡演名（曾真实发生） |
| 历史场馆经验 | 是否开过同级别场馆、几次、口碑 | 忽略"上次开砸了"这类负资产 |
| 票价结构 | 最低-最高价、档位数量 | 不写票价，客单价与转化率无从校准 |
| 已知负资产 | 争议、口碑滑坡、审美标签（如"土"） | 只写优点，导致设计踩雷 |

### 2.1.5 选填信号：票务平台「想看」数（v5.6）

大麦等票务平台的"想看"人数是唯一细化到"这一场"的公开人气信号，但**不是必填项，更不是决策输入**：它常在开票后才进入爆发期，出现时点因场馆/艺人/宣发节奏而异，可能晚于周边的生产窗口。规则：

- 可得 → D1 填「数值 + 采集日期」，只用于**升级/降级**上座率与 w 的置信度标注，永不直接推 N；
- 不可得 → 写「不可得」，不阻塞决策；
- 采集规范、三条使用规则与场景表见 `quant-model.md` §八。

### 2.2 生涯阶段 → 叙事强度（决定稀缺款的上限）

| 阶段 | 特征 | 叙事强度 | 对稀缺款的含义 |
|------|------|---------|---------------|
| 上升期 | 首次大场馆、粉丝高速扩张 | 中 | 稀缺款少做，重引流与传播 |
| 巅峰期 | 连续售罄、话题密集 | 高 | 稀缺款可做，但需"本场专属"而非"生涯纪念" |
| 稳定期 | 巡演常态化、粉丝结构稳定 | 中低 | 稀缺款靠工艺与编号，不靠故事 |
| **复兴期** | 出圈、代际扩张（例：翻唱爆火后） | **高** | 「被重新发现」是可用的强叙事 |
| 告别期/阶段收官 | 明确的时间边界 | 极高 | 稀缺款上限最高，但**语气必须克制**（见 D4 档期规则） |

### 2.3 IP 资产缺口表（比资产清单更重要）

| 资产类型 | 有/无 | 缺口对设计的影响 |
|---------|-------|-----------------|
| 稳定视觉符号（LOGO/图腾/固定配色） | | 无 → 必须原创重绘，不能用"艺人形象"顶上 |
| 卡通/IP 形象（可延展） | | 无 → 放弃娃类、盲盒类、挂件家族 |
| 应援体系（色/手势/口号） | | 无 → 应援类整体降权，不做"应援棒第二根" |
| 可引用文本资产（歌词/口头禅/梗） | | 有 → 符号从**文本**里长出来，这是最强路径 |

> **判断口诀**：符号从"人"里长不出来，就从"歌"里长出来；从"歌"里也长不出来，就只能从"场"里长出来（场馆/日期/场次）。

### 2.4 输出格式

```
## D1 艺人档案与 IP 资产
### 1. 基础档案（12 项表）
### 2. 生涯阶段判定：{阶段}，依据：{2-3 条 A 级事实}
### 3. IP 资产盘点与缺口（资产表 + 缺口表）
### 4. 我们不知道什么：{1-3 条}
### 5. → 决策含义（3-5 条，带编号 D1-01…）
```

## 3. D2｜粉丝圈层与审美权重

### 3.1 结构画像（5 个数，能查就查，查不到标 C）

| 指标 | 用途 |
|------|------|
| 年龄结构 | 决定符号年龄层（梗的世代、字体、配色饱和度） |
| 性别结构 | 决定品类权重（配饰 vs 服装 vs 摆件） |
| 城市/跨城比例 | 决定"便携性"权重与行李体积上限 |
| 家庭/结伴比例 | 决定套装与礼盒结构、客单价上限 |
| 平台分布 | 决定投放节奏（见 `channel-playbook.md`） |

### 3.2 审美权重表（必须合计 100%，必须带依据）

| 审美倾向 | 权重 | 依据（样本/高频词/评论） | 对应品类 |
|---------|------|------------------------|---------|
| | % | | |

> 权重不带依据 = 编的。允许写「B 级：小红书 50 条高赞笔记观察」，不允许写「感觉」。

### 3.3 组织形态判定（决定运营打法）

| 形态 | 特征 | 运营含义 |
|------|------|---------|
| 饭圈型 | 后援会/打榜/站姐/集资 | 可做预售冲量、编号抢购、粉丝群接龙 |
| **无组织型** | 无后援会、无打投、自发聚集 | **不做"抢"的机制**，做"到场就能买到"；私域弱，靠平台公域 |
| 家庭型 | 全家/结伴观演 | 套装、亲子尺码、礼盒优先；限购无意义 |
| 圈层亚文化型 | 强身份认同（摇滚/说唱/民谣） | 做"懂的人才懂"的暗号型设计 |

### 3.4 审美禁区（必须具体到"不能做什么"，不是"要高级"）

格式：`{禁忌项} → 为什么 → 正确替代`
例：`艺人面部照片做主视觉 → 粉丝认为"廉价""像微商应援" → 改用歌词排版/抽象图腾`

### 3.5 → 决策含义

必须至少覆盖：应援类该不该做、符号从哪来、客单价上限、投放主战场。

## 4. D3｜演唱会情绪地图与篇章

### 4.1 六要素（缺一不可）

| 要素 | 说明 |
|------|------|
| 主题 | 本站专属主题名（巡演名 ≠ 本站主题） |
| 核心情绪 | 一句话，不超过 20 字 |
| 主色调 | 主色 + 辅色，附 HEX；与官方主视觉一致 |
| 视觉核心元素 | 3-5 个，必须能落到工艺上 |
| 关键歌词意象 | 2-4 句，标注出处与授权状态 |
| 叙事弧线 | 4-6 段，一句话一段 |

### 4.2 时间段表（本册最容易被跳过、也最影响陈列与备货的部分）

| 段落 | 时长 | 情绪状态 | 代表曲目方向 | 绑定 SKU 方向 |
|------|------|---------|-------------|--------------|
| | 约 X 分钟 | | | |

> 这张表直接决定三件事：**摊位动线**（哪一段该把高客单推到前面）、**补货时点**（哪一段后必然断码）、**限购触发**（哪一段出现抢购）。

### 4.3 场次结构变量（多场连开必做）

| 变量 | 例 | 用法 |
|------|----|------|
| 首场 | 媒体场、口碑场 | 首发限量、内容拍摄 |
| 生日场/纪念场 | 官方标注的特殊场 | **独立 SKU 或独立配色**，溢价能力最强 |
| 末场/收官场 | 情绪最浓 | 礼盒、编号、告别叙事 |
| 加场 | 临时加开 | 说明需求溢出，可上调产量（但需交期允许） |

### 4.4 → 决策含义

必须至少覆盖：陈列动线、稀缺款落点、场次差异化的做法。

## 5. D4｜城市与场馆

### 5.1 城市四个数

| 指标 | 取值 | 依据 |
|------|------|------|
| 推荐客单价区间 | | |
| 限量款接受度 | 高/中/低 | |
| 跨城观演比例 | % | |
| 地缘叙事可用性 | 高/中/低 | 本地粉丝对"这个城市/这个场馆"的情感浓度 |

### 5.2 场馆 IP 强度（六维，各 10 分）

| 维度 | 分数 | 依据 |
|------|------|------|
| 艺人国民度 | /10 | |
| 粉丝忠诚度 | /10 | |
| 本场稀缺性 | /10 | 首次/收官/唯一性 |
| 社交传播力 | /10 | |
| 场馆品牌价值 | /10 | |
| **综合** | /10 | |

### 5.3 联名类型判定（决定场馆元素能不能上主视觉）

| 类型 | 条件 | 场馆元素用法 |
|------|------|-------------|
| 艺人主导型 | 艺人 IP ≫ 场馆 | 只做隐性层 |
| **强平衡型** | 两者接近满分 | 可上辅助层，限量款可上主视觉 |
| 场馆主导型 | 场馆 ≫ 艺人（拼盘/庆典） | 场馆可做主视觉，艺人做辅助 |

三层定义：**隐性层**（水洗标/内页/经纬度）→ **辅助层**（走边/暗纹/局部轮廓）→ **主视觉层**（封面构图）。

### 5.4 档期结构（v5.4 新增，凤凰传奇案例沉淀）

| 情形 | 性质 | 用法 | 红线 |
|------|------|------|------|
| 场馆年度首场 | "开门红"，场馆方有做好动机 | 争取资源、展位、官方宣发 | 不可宣称"唯一" |
| 场馆年度收官 | 阶段终点 | ①授权谈判筹码 ②编号/纪念的合法性来源 | 只说"2026 年最后一场"这类**可验证事实** |
| 场馆后续长期无演出 | 结构性稀缺 | 写入礼盒内页等**第二层叙事** | 禁用"绝版/永不再有/最后机会" |
| 场馆改造/闭馆 | 客观事实 | 与场馆联名的正当理由 | 不得暗示"场馆要拆"等误导 |

> **一句话规则**：档期稀缺性是**授权筹码**和**内页小字**，不是海报大字。做成主视觉就是收割，粉丝会立刻闻出来。

### 5.5 → 决策含义

必须至少覆盖：场馆元素层级、客单价、限量款是否加码。

## 6. D5｜经纪公司与授权链

> 完整方法与模板见 `references/agency-authorization.md`。本章只规定"必须回答什么"。

必答 6 问：

1. **谁签字**：唱片公司 / 经纪公司 / 工作室 / 主办 / 场馆，各自批什么？
2. **签多久**：从接触到书面授权，历史上用了多少天？本项目的倒排起点在哪一天？
3. **签什么范围**：品类、渠道（现场/线上）、地域、期限、是否独家？
4. **分多少**：分成比例、保底、最低量、结算周期。
5. **谁审图**：几轮审核、每轮几天、谁有最终否决权（艺人本人？经纪？版权？场馆？）。
6. **历史口碑**：有没有临期才定案、多供应商并行、口头承诺不落地的前科？

评分沿用 `artist-ip-ecosystem.md` §组织与授权可行性（3-15 分），并在此写清"评分 → 交付模式降级"的结论。

## 9. 反模式清单（出现即返工）

| # | 反模式 | 为什么致命 |
|---|--------|-----------|
| 1 | 百科搬运：写"出道 25 年"却不给决策含义 | 读者拿不到任何可用信息 |
| 2 | 无来源百分比：审美权重"凭感觉"分配 | 后面所有结构比例都建在沙上 |
| 3 | 只写有利面：不写"不知道什么" | 数字必然虚高，交付后被现实打脸 |
| 4 | 依据章里出现具体款式、定价、配额 | 顺序倒置，等于先有结论再找理由（只允许写品类与工艺方向） |
| 5 | 把"粉丝很热情"当结论 | 热情无法换算成件数 |
| 6 | 场馆元素当主视觉（非强平衡型） | 侵权风险 + 粉丝反感 |
| 7 | 引用歌词不标授权状态 | 上线前被卡，整批改稿 |

## 10. 分档裁剪（依据部也要按交付模式裁剪）

| 交付模式 | D1 | D2 | D3 | D4 | D5 | D6 | D7 |
|---|---|---|---|---|---|---|---|
| 全案 | 全量 | 全量 | 全量 | 全量 | 全量 | 全量 | 全量 |
| 标准案 | 全量 | 全量 | 时间表必留 | 全量 | 结论 | 全量 | 半页 |
| 精简案 | 1 页 | 参数+禁区 | 段落表 | 档期+场馆层级 | 结论 | 结论 | 略 |
| **急救案** | **半页（只留主体/阶段/票价）** | **参数+禁区（决定做什么）** | **段落表（决定摆在哪）** | **档期（决定能不能用场馆）** | **1 行：授权是否已到手** | 略 | 略 |

> 急救案不等于"不做依据"。恰恰相反：时间越紧，越只能靠依据做判断，因为没有试错空间。
