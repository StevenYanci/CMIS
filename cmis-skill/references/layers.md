## Layer 0｜项目分诊

### 目标
在任何分析开始前，确定**项目档位（S/M/L）**与**交付深度**，避免用同一套深度应对所有项目。

### 执行

1. 计算 `D-day = 演唱会日期 − 今日`
2. 按场馆容量与艺人量级判定 S/M/L（规则见 `SKILL.md` Layer 0）
3. 按 D-day 判定交付模式：≥60天 全案 / 30-59天 标准案 / 15-29天 精简案 / <15天 急救案
4. 若 D-day < 45 天，**立即读取 `references/supply-chain.md`**，先做交期可行性预判，再决定 SKU 候选范围

### Layer 0 输出（放在方案开头，2-4行）

```
【项目分诊】档次：M（单场约9万人，2场）
【距演出】16 天 → 交付模式：急救案
【结论】按极限交期执行：必保4款 + 演后预售3款，不再讨论重开模品类
```

## Layer 1｜数据采集与艺人分析（含专属符号词库构建）

### 目标
通过 web search 构建艺人的**实时全景画像**，并提炼出结构化的「艺人专属元素词库」与「禁用元素黑名单」，作为后续所有SKU设计的强制约束基准。

### 必须检索的内容

#### A. 基础资料
- 艺人/组合简介、出道背景
- 代表作品（歌曲/专辑/影视）
- 历史演唱会规模与口碑
- 官方应援色、粉丝昵称
- 粉丝文化特征（应援方式、圈内文化）

#### B. 近3年巡演视觉沉淀（新增，经纪公司第一审核权重）
搜索关键词参考：`艺人名 巡演 视觉`、`艺人名 演唱会 舞台`、`艺人名 演唱会 主视觉`

重点提取：
| 项目 | 内容 |
|------|------|
| 固定主色调与色系变化 | |
| 巡演LOGO/字体风格 | |
| 舞美结构特征（装置/光墙/裸眼3D等） | |
| 经典舞台造型与固定出场姿势 | |
| 视觉调性关键词（冷/暖/科幻/怀旧/极简等） | |

> ⚠️ 这3年的积累是"艺人官方视觉基因库"，本场限定款的设计必须与之调性一致，不能断层。

#### C. 实时热点
搜索关键词参考：`艺人名 最近 热搜`、`艺人名 小红书`、`艺人名 粉丝`

重点提取：
| 项目 | 内容 |
|------|------|
| 最近热搜话题 | |
| 最近爆火内容 | |
| 粉丝当前情绪方向 | |
| 社交高传播内容 | |
| 是否有争议或特殊事件 | |

#### D. 音乐内容沉淀（设计素材来源）
- 高频歌词意象（出现频率最高的意象词汇）
- 核心专辑概念与视觉
- 贯穿多年的创作主题、个人人生态度
- 经典金句、口头禅、演唱会口号

#### E. 独有标志性符号（最高优先级设计素材）
- 专属手势
- 固定舞台道具（如：麦架、特殊乐器、标志性演出服元素）
- 个人LOGO或艺名变体字
- 应援符号（荧光棒颜色/形状/粉丝应援手势）
- 经典动作剪影

#### F. 粉丝审美分析
判断粉丝群体的主流审美偏向（可多选，需标注权重）：

| 审美类型 | 权重 | 依据（样本/高频词/评论） | 当下粉丝偏好信号 |
|---------|------|----------------------|----------------|
| 高级极简 | | | 低饱和、无衬线字体、留白 |
| 暗纹/浮雕质感 | | | 肌理感、触觉体验、隐形元素 |
| 文艺复古 | | | 胶片感、旧纸质、黑胶风 |
| 潮流街头 | | | 解构、混搭、oversize |
| 可爱治愈 | | | 圆润、柔和色、毛绒质感 |
| 二次元 | | | 动漫美学、夸张色彩 |

> ⚠️ 三条规定（v5.4）：①权重必须**合计 100%**；②每行必须写依据（样本量或高频词），写不出来就标 C 级假设；③权重会直接决定第 9 章的品类结构比例，不能事后改。
> ⚠️ 审美判断错误是文创失败第一大原因；需综合微博超话、小红书、粉丝群高频词交叉验证。排斥廉价卡通风和夸张大LOGO是当下多数粉丝群的共识。

#### F2. 粉丝结构五数（v5.4 新增，能查就查）

| 指标 | 数值 | 用途 |
|------|------|------|
| 年龄结构 | | 决定梗的世代、字体、配色饱和度 |
| 性别结构 | | 决定配饰 vs 服装 vs 摆件权重 |
| 跨城观演比例 | | 决定便携性权重与体积上限 |
| 家庭/结伴比例 | | 决定套装与礼盒结构、客单价上限 |
| 组织形态（饭圈型/无组织型/家庭型/亚文化型） | | 决定"抢"还是"到场就能买" |

> 组织形态判错的代价：对无饭圈群体做"限量抢购编号"，只会制造黄牛；对饭圈做"敞开卖"，会失去稀缺溢价。

#### G. 粉丝聚集线上平台分析（v5.2 恢复）

> 目的：明确"去哪说、谁去说、什么时候说"。做不出平台结论的运营方案，等同于"发个微博"。

**检索方向**：`艺人名 超话`、`艺人名 粉丝群`、`艺人名 抖音 话题`、`艺人名 小红书`、`艺人名 后援会`

**提取内容**：

| 项目 | 内容 |
|------|------|
| 第一聚集平台 | 粉丝密度最高、话题最活跃的平台 |
| 晒单/种草主战场 | 开箱、repo、穿搭内容最集中的平台 |
| 最有效私域 | 后援会活跃在微信群/QQ群/贴吧？谁有组织力？ |
| 粉丝代际 × 平台对应 | 老粉/核心粉/新粉各自在哪 |
| 平台特殊现象 | 如"佛系不打榜""男性粉丝主导传播""跨地域私域" |

**输出格式**：

```
【粉丝聚集线上平台分布】
- 平台分布：微博XX% / 抖音XX% / 小红书XX% / 微信群XX% / QQ群XX% / 贴吧XX% / B站XX%
- 第一聚集平台：[平台]（依据：____）
- 晒单主战场：[平台]，原因：____
- 最有效私域：[渠道]，运营动作：____
- 首发顺序建议：____ → ____ → ____
```

> 详细平台职能、代际映射与投放节奏见 `references/channel-playbook.md`。此处只需给出结论，不展开执行细节。

#### H. 圈层类型判定（v5.3 新增）

> 先判"这是哪一类粉丝"，再取参数。用流行歌手的基准去套民谣/摇滚/唱作型，会系统性错配品类结构与销售周期。

| 类型 | 判定特征 | 参数影响 |
|------|---------|---------|
| 流量偶像型 | 人设/综艺/短视频驱动，组织化应援强 | w 高、应援类占主导、长尾短 |
| 大众流行型 | 作品国民度高，购票人群杂 | 全品类均衡 |
| 创作/唱作型 | 作品与人格绑定，粉丝重"懂"、拒绝表演性消费 | **日常配饰强、应援类弱、长尾长（λ1.3-1.6）** |
| 摇滚/独立型 | 圈层认同强，反商业化 | 海报/黑胶/织物，忌"塑料感" |
| 说唱/潮流型 | 穿搭外显、潮流属性 | 服饰/帽/配饰 |
| 资深唱将型 | 中年与家庭观众、消费力强 | 高品质实用件、礼盒 |

**输出一句话**：`圈层类型：创作/民谣型（依据：作品驱动、粉丝内化表达、无组织化应援）`
参数表与赵雷反例拆解见 `references/artist-archetypes.md`。

> ⚠️ **符号四参是 Gate A 的前置条件，不是补充信息。** 一句话自检：
> **「能不能说出三件只有他才有的视觉符号？」** 说不出 → O 低 → 走 S1 拦截，
> 圈层通常同时应改判为**传唱/集体释放型**（`artist-archetypes.md` §二.5）。
> **不要用观众的年龄/性别来判断这件事**——凤凰传奇 66% 观众在 18-29 岁、女性约七成，依然是典型 O 低。

**必须同时输出「IP 资产缺口表」**（稳定视觉符号 / 卡通形象 / 应援体系 / 可引用文本资产 各有或无），它直接决定符号从哪里长出来：

> 符号从"人"里长不出来，就从"歌"里长出来；从"歌"里也长不出来，就只能从"场"里长出来（场馆/日期/场次）。
>
> **v6.0 补一条更前置的判断**：若三级都长不出来（典型如核心资产是**旋律与集体行为**），
> 不要继续往下找符号了，改走 `symbol-system.md` §一的三条代偿路径：**声音实体化 / 行为凭证化 / 歌词文本化**。
> 做的是"证据"，不是"形象"。

## Layer 1.5｜艺人自有IP生态与分流率分析（核心新增层）

> 📌 此层为 CMIS 关键差异化能力，必须执行，不可跳过。
> 详细方法论与案例库见 `references/artist-ip-ecosystem.md`，执行本层前应先读取该文件。

### 目标

回答核心问题：**这位艺人的粉丝，除了演唱会限定渠道之外，还有多少其他长期、稳定、低门槛的方式可以获得与其相关的产品？** 这直接决定演唱会限定款的"边际稀缺性"和最终产量基数。

### 必须检索的内容（web search）

| 检索方向 | 搜索关键词参考 |
|---------|---------------|
| 自有品牌 | `艺人名 品牌`、`艺人名 创业`、`艺人名 代言 长期` |
| 常规文创产品线 | `艺人名 官方店铺`、`艺人名 周边 官网`、`艺人名 文创` |
| 直播带货/电商 | `艺人名 直播带货`、`艺人名 抖音 直播`、`艺人名 淘宝店` |
| 往届演唱会限定款销售反馈 | `艺人名 演唱会 周边 测评`、`艺人名 演唱会 周边 销量`、`艺人名 演唱会 限定 好评/差评` |

### 执行步骤

#### Step 0：经纪公司与授权档案（D5，v5.4 新增，先于一切销售测算）

> 模板与合同条款见 `references/agency-authorization.md`。此步不产出"销售判断"，只产出"能不能做"的结论。

必须填完的 10 项：公司主体 / 权限范围 / 决策人 / 决策链长度 / 历史审批周期（要天数）/ 审核轮次与时限 / 分成与保底 / 排他习惯 / 历史口碑 / 本案特殊结构（组合双人需共签、家族企业等）。

同时给出**五方决策链**归属：艺人本人（肖像与审美否决）、经纪/工作室（合同主体）、唱片公司（词曲与录音）、主办（摊位与动线）、场馆（名称与建筑元素）。

**必答三句**（写不出这三句，不许进入 Layer 2）：
1. 谁签字：____
2. 最晚哪一天必须拿到书面授权：____（= 首波下单日 − 授权后素材交付与打样天数）
3. 拿不到时的 Plan B：____（零授权依赖品类 + 演后预售）

#### Step 1：渠道盘点
按五个分流来源逐一排查（参考 `artist-ip-ecosystem.md` 中的分类A-E）：
- A. 自有品牌/跨界品牌（如餐饮、潮牌等与个人IP高度绑定的商业实体）
- B. 长期常规文创产品线（官方店铺常驻款）
- C. 直播带货/常态化电商渠道
- D. 历史限定款"通货化"程度（历年设计是否高度相似）
- **E. 现场自带产品与同场竞争（v5.3）**：艺人自有餐饮/饮料/服饰是否进场设摊？主办方与赞助商是否占用同品类？

> E 类是最狠的分流——同场景、同预算、同时间。谢霆锋场内自带汉堡、饮料、T恤、方巾，直接把同品类需求吃掉。发现 E 类冲突时，`k` 再乘 0.85-1.0 的现场修正。

#### Step 2：四维度评分（每项1-5分）

参照评分表，对每个维度打分，求和得到综合评分（4-20分）。

#### Step 3：分流率分级与产量调整系数

| 总分区间 | 分流率等级 | 产量调整系数 |
|---------|-----------|------------|
| 4-7分 | 低分流 | ×1.0 |
| 8-12分 | 中分流 | ×0.8-0.9 |
| 13-16分 | 高分流 | ×0.6-0.75 |
| 17-20分 | 极高分流 | ×0.4-0.6 |

> ⚠️ **v5.2 修正**：此系数作用于「购买意愿率 w」（见 `quant-model.md` 的 `D = N × w × k`），而不是在测算完成后直接乘到首批量上。旧做法会与容量测算重复打折，导致预测失真。

#### Step 4：差异化校验清单

输出以下三项清单，供 Layer 5 设计SKU时强制参照：
1. **需规避的品类**：与艺人现有长期产品重复的品类
2. **需规避的视觉符号**：艺人个人IP已大量铺货的符号/形象
3. **必须强化的"限定专属"元素**：场馆名、日期、编号、限定色等不可复制要素

#### Step 5（可选）：渠道协同建议

若艺人自有渠道（尤其直播带货）较强势，评估是否适用以下协同方案：
- 方案A：限定编号款 + 直播间专属补货
- 方案B：艺人长期爆款的"演唱会特别版"
- 方案C：与艺人自有品牌的一次性联名

标注"需与艺人团队对接确认"。

#### Step 6：组织与授权可行性（v5.3 新增，必做）

> 这一项不问"卖不卖得动"，只问"来不来得及开始卖"。
>
> ⚠️ **v6.1 修正**：周杰伦鸟巢站的旧教训写作"授权链混乱、临近演出仍未定案，销售反不如同量级艺人"——**观测真，归因错**。

## Layer 2｜演唱会情绪系统与篇章结构分析

### 目标
将演唱会解码为**情绪产品的设计蓝图**，并识别演唱会是否存在"篇章叙事结构"以驱动系列化产品设计。

### 执行步骤

#### A. 主题解析
搜索演唱会官宣信息、主视觉海报、官方宣传文案。

提取：
- 主主题（科幻/怀旧/情绪/嘉年华/史诗等）
- 情绪关键词（3-5个）
- 世界观设定
- 叙事方向

#### B. 视觉元素提取
从官宣物料中提取：
- 主色调（精确到色值范围）
- 辅色
- 主视觉元素（图形/符号/材质感）
- 字体风格
- 整体调性（冷/暖/中性）

#### C. 篇章/章节结构识别（新增，高价值）

> 许多大型巡演会设定分篇章叙事结构（如：第一幕「少年」→ 第二幕「流浪」→ 第三幕「归来」），这是驱动"系列化产品"设计的天然逻辑。

**检索方式**：搜索 `艺人名 演唱会 篇章`、`艺人名 巡演 章节`、`艺人名 演唱会 setlist 分段`

**判断与处理**：

| 情况 | 处理方式 |
|------|---------|
| 有明确篇章划分（官方有命名） | 提取每个篇章的意象/情绪/视觉关键词，作为分层系列产品的独立设计方向 |
| 有隐性段落感（高低潮有规律但无官方命名） | 自行归纳2-3个"情绪段落"，用于绑定不同SKU的情感定位 |
| 无明显结构 | 按标准情绪曲线处理即可 |

**篇章产品化逻辑**（适用于有篇章结构的演唱会）：

- 每个篇章对应一组限定SKU或一款限定色/限定图案
- 系列产品可形成"集齐感"，激励粉丝多件购买
- 礼盒可按篇章命名和设计（如：「第一章·少年礼盒」）
- 引流款可做通用款，品牌款/稀缺款可做篇章专属款

#### D. 情绪曲线构建

根据艺人演唱会历史规律与本次主题，构建情绪时间轴：

| 阶段 | 时长估算 | 情绪状态 | 代表曲目（如有） | 适配SKU方向 |
|------|---------|---------|----------------|------------|
| 开场 | | 兴奋/期待 | | 应援类 |
| 上升段 | | 热烈/投入 | | 互动类 |
| 抒情段 | | 共情/泪点 | | 歌词/情感类 |
| 高潮段 | | 释放/狂欢 | | 记录类 |
| Ending | | 不舍/纪念 | | 纪念/收藏类 |

#### E. 场次结构变量（v5.4 新增，多场连开必做）

| 变量 | 识别方式 | 用法 |
|------|---------|------|
| 首场 | 巡演首站/媒体场 | 首发限量和内容拍摄；首场售罄数据决定返单 |
| **生日场/纪念场** | 官方售票页标注、艺人纪念日 | **独立 SKU 或独立配色**，溢价能力最强，但要提前 45 天排产 |
| 末场/收官场 | 本站最后一场 | 礼盒、编号、告别叙事集中在此 |
| 加场 | 临时加开 | 需求溢出信号，可上调产量（须交期允许）；也说明售票策略偏保守 |

> 六场连开且无差异，等于把六次机会当成一次用。场次差异化是**零成本增量**：同一 SKU 换配色换编号，溢价 10-20%，成本几乎不变。

## Layer 5｜商品决策与爆款预测

> 综合 Layer 1-4（特别是 Layer 1.5 的分流率数据）所有分析结果，生成SKU矩阵

---

### ⛔ 首要警告：禁止从品类库出发选品

**造成"所有艺人产品都很像"的根本原因**：先想"我们要做T恤、钥匙扣、金属徽章"，然后再往里套艺人元素。这是错误的路径。

**正确路径是反向的**——先从 Layer 1 的「艺人专属符号词库」出发，问：

> **"这个符号/情绪/意象，最适合被做成什么形态的产品？"**

然后再把答案套进四象限定价结构。

看数据中的高差异化案例：
- 「五球」符号 → 拼图冰箱贴 + 胡萝卜手机支架（不是先想做冰箱贴，而是"五球能做什么"）
- 「快乐」情绪 → 发声趣味罐 + NFC感应贴（触碰就播放，快乐立刻发生）
- 「磁带时代感」符号 → 磁带造型钥匙扣（复古符号直接物化）
- 「龙拳」曲目IP → 大娃造型荧光棒（具体IP形象做成应援工具）
- 「八花」演唱会专属视觉 → 毛绒挂件（演唱会视觉符号直接产品化）

### Step 0：专属符号产品化推导（必须最先执行）

**在生成任何SKU之前**，对 Layer 1 词库中的每一个「标志性符号/独有元素」，逐一完成以下推导：

| 符号/元素 | 符号特征 | 产品化方向候选 | 可行性判断 |
|---------|---------|--------------|----------|
| [符号1] | 可视化图形/文字/声音/互动 | [候选品类A] / [候选品类B] | 选[A]，原因：[原因] |
| [符号2] | | | |
| [演唱会专属意象] | | | |
| [粉丝圈专属文化符号] | | | |

**推导规则**：
- 图形类符号（五球、八花、龙拳角色）→ 优先考虑立体化/毛绒化/异形化，而非平面印刷
- 声音/音乐类符号（声纹、代表曲、口头禅）→ 优先考虑发声产品/声纹暗纹/歌词载体
- 互动/情绪类符号（「快乐」「陪伴」「干杯」）→ 优先考虑有互动体验的产品形态（NFC、发光、可触发）
- 时代感/怀旧类符号（磁带、黑胶）→ 优先考虑同类型产品的造型化演绎
- 稀缺/仪式感类符号（编号、纪念日）→ 优先考虑带唯一标识的收藏品形态

**本步骤输出**：「符号驱动SKU候选清单」——这是后续产品矩阵的**第一优先来源**。

### ⚠️ 分流率差异化校验（执行前必读）

生成每一个SKU时，还须对照 Layer 1.5 输出的"差异化要求清单"逐一检查：

1. 该SKU品类是否在"需规避的品类"列表中？若是，需重新设计或调整工艺/版型/定位使其明显区分

3. 该SKU是否包含至少一项"必须强化的限定专属元素"（编号/日期/场馆元素等）？
4. **该SKU品类是否与"艺人现场自带货"重叠？**（v5.3）若重叠且我方无工艺或限定优势，标记为 ⚠️ 同场竞争，建议改为互补品或更换品类
5. **该SKU是否符合本次圈层类型的结构偏好？**（v5.3）民谣/创作型若出现"应援棒 + T恤"为主的矩阵，视为结构错配，需重排

任何SKU若前两项判定"高重复"且第三项"无"，标记为 **🔴 高分流风险SKU**，建议替换。

### 爆款概率评分模型（v5.2 修正为百分制）

> 旧版标注"各1-5分，总分35分"，但表格给了 ×2 权重，实际满分是 50 分，阈值却按 35 分设定——不同批次跑出的分数不可比。现统一为**百分制**。

每个SKU按 7 个维度评分（各 1-5 分），加权后换算为 100 分制：

| 维度 | 权重 | 说明 |
|------|------|------|
| 情绪强度 | 25% | 与粉丝当前情绪热点、演唱会篇章的契合度 |
| 社交传播性 | 20% | 适合拍照/分享/炫耀的程度 |
| 粉丝契合度 | 20% | 与粉丝审美偏好、消费习惯的匹配度 |
| 收藏价值 | 10% | 未来是否会保留/升值 |
| 使用频率 | 10% | 日常使用频率 |
| 城市适配度 | 8% | 对本城市消费者的吸引力 |
| 潮流适配度 | 7% | 与当前文创趋势的契合度 |

**计算**：`总分 = Σ(维度评分 × 权重) × 20`（满分 100）

**等级判定**：

| 总分 | 等级 | 动作 |
|------|------|------|
| ≥ 80 | ⭐⭐⭐ 强烈推荐 | 主打款，资源优先（中心陈列位、内容主推） |
| 65-79 | ⭐⭐ 稳健款 | 正常投放，作为利润与结构支撑 |
| 45-64 | ⭐ 补充款 | 控制数量，仅用于丰富结构或低价引流 |
| < 45 | 建议放弃 | 重新设计符号或直接剔除 |

> 💡 两点纪律：
> 1. **评分只用于本项目内部排序**，不可跨项目比较（不同项目基准不同）。
> 2. 分流率系数 `k` **不乘入评分**——它作用于销量测算（见 `quant-model.md`），两者独立。评分回答"产品好不好"，`k` 回答"市场被分走多少"。

### Gate B｜定量闸判定（本层结束时必须给出）

对每个SKU同时校验三项，任一不达标即需调整：

| 校验项 | 阈值 | 不达标处理 |
|--------|------|-----------|
| 预测销量 vs MOQ | 销量 ≥ MOQ | 合并下单 / 提价 / 换规格 / 剔除 |
| 毛利率 | ≥ 象限下限（引流45%/利润55%/品牌50%/稀缺55%） | 调价、换工艺、降低包装成本 |
| 售罄率预估 | ≥ 60% | 下调数量，或转"演后预售款" |

> 计算口径与参数见 `references/quant-model.md`。策划书第 8 章的数字必须与本层判定一致。

### 高级稀缺性工艺体系（核心竞争壁垒）

> 行业90%供应商只做印花/印LOGO/印歌词，以下是真正让方案通过经纪公司筛选的差异化能力。
> 详细工艺选型参考见 `references/sku-library.md`。

#### 工具1：数据化专属暗纹设计

将本场演唱会的**独有数据**转化为产品的视觉底纹/肌理，做到"每一件都属于这一场"。

| 数据来源 | 转化方式 | 适用产品 |
|---------|---------|---------|
| 本场演唱会代表曲目的声纹波形 | 提取波形线条，转化为产品底纹/压纹/包装暗纹 | T恤内里、礼盒内衬、金属章纹路 |
| 演唱会场馆灯光节拍数据/高光时刻 | 转化为抽象光轨图案 | 印花图案、透卡底纹 |
| 演出曲目列表/歌词字频 | 微缩字体排版为底纹 | 包装内页、票根套内层 |
| 演唱会举办时间（年/月/日/时/分） | 转化为极简坐标系/数字排列 | 金属刻印、压纹 |

**操作方法**：向设计团队提供"数据源描述"，指定转化形式，输出为矢量图案。

#### 工具2：隐藏彩蛋设计（肉眼低调，有条件可见）

> 这是粉丝"发现-尖叫-分享"链路的触发器，社交传播力极强。

| 彩蛋类型 | 实现方式 | 适用场景 |
|---------|---------|---------|
| 灯光彩蛋 | 用荧光/夜光油墨印刷隐藏图案，演唱会灯光下才可见 | T恤、毛巾、帆布袋 |
| 扫码彩蛋 | 产品上印隐藏二维码，扫后跳转艺人限定内容（视频/音频/壁纸） | 礼盒内卡、贴纸 |
| 局部放大彩蛋 | 宏观看是正常图案，放大后出现隐藏歌词/符号 | 海报、艺术印刷品 |
| 角度彩蛋 | 不同角度下呈现不同图案（幻彩/镭射材质） | 亚克力卡、金属章 |

> ⚠️ 彩蛋设计必须基于 Layer 1 的「艺人专属符号词库」，彩蛋内容必须是"懂的人才会尖叫"的艺人专属元素，而非通用装饰。

#### 工具3：唯一编号体系

将"稀缺性"从感觉变为可验证的事实。

| 编号类型 | 格式示例 | 适用SKU | 成本影响 |
|---------|---------|---------|---------|
| 全球唯一流水编号 | No.0001/2000 | 稀缺款礼盒、限量海报 | 低（印刷/激光刻印） |

> 编号体系必须在策划书中明确说明"限量总数"和"编号规则"，限量数量是对外宣传的核心卖点。

根据艺人调性和SKU档位，匹配相应工艺：

## Layer 6｜落地校验（供应链 + 合规）

> 📌 本层为 v5.2 新增。目的：在方案变成"承诺"之前，把做不出来、带不进场、卖不合法的东西剔掉。
> 执行前读取 `references/supply-chain.md` 与 `references/compliance.md`。

### A. 交期可行性（逐SKU）

1. 取每个 SKU 的标准工期与加急最短工期
2. 计算 `可用天数 = D-day − 留白（生产后物流+质检+布展，建议 8-10天）`
   - **若书面授权尚未拿到，可用天数需再扣除"预计授权等待期"**（默认 30-45 天，或按 Layer 1.5 Step 6 的评分取值）
3. 判定：

| 判定 | 条件 | 动作 |
|------|------|------|
| ✅ 可行 | 可用天数 ≥ 标准工期 | 正常排产 |
| ⚠ 紧张 | 加急最短 ≤ 可用天数 < 标准工期 | 走加急，标注加价与供应商条件 |
| ❌ 不可行 | 可用天数 < 加急最短 | 改为 L1-L4 降级方案（现货改装/包装差异化/演后预售）或剔除 |

4. 输出 T-minus 倒排表与锁货优先级（4款基本盘优先）

### B. 合规校验（逐SKU）

按 `compliance.md` 六条一票否决线逐项打勾：安检、电池/电子、版权、场馆IP、资质、宣传表述。
任一为红 → 必须改设计、换形态或删除。

### C. Gate C 判定

| 结果 | 条件 | 动作 |
|------|------|------|
| 🟢 通过 | 全部SKU交期与合规均为可控 | 进入 Layer 7 |
| 🟡 部分降级 | 有SKU转演后预售或改现货方案 | 在方案中明确标注"降级原因 + 销售方式变化" |
| 🔴 方案重做 | 核心SKU（含主推款）不可行 | 回到 Layer 5 重排矩阵，不得带病输出 |
