# CMIS — 经纪公司、授权链与合同要点

> 为什么单列成册：**文创项目最常见的失败不是"卖不动"，是"做不出来"。** 周杰伦鸟巢案例里，顶流 IP、满场票房、粉丝购买力全部齐备，最后败在"授权临近演出仍未定案"——D-day 看似 60 天，有效可执行天数只剩 15 天。
> 所以授权不是一个"法务流程"，它是**排产的第一道约束**，比设计、比选品都靠前。

---

## 一、五方决策链：谁批什么

| 角色 | 通常批什么 | 不批会怎样 | 沟通优先级 |
|------|-----------|-----------|-----------|
| **艺人本人** | 肖像、签名、口头背书、审美否决 | 设计被全盘推翻（最后一天才发生的最常见） | ★★★★★ |
| **经纪公司/工作室** | 合作主体、品类范围、分成、排他 | 合同签不下来 | ★★★★★ |
| **唱片公司/版权方** | 词曲、录音制品、专辑视觉、MV 素材 | 歌词不能印、音频不能录（NFC 类直接作废） | ★★★★ |
| **巡演主办/承办** | 现场摊位、动线、销售时段、分成 | 货到了进不了场 | ★★★★ |
| **场馆/场地方** | 场馆形象、名称、建筑元素、"鸟巢"字样 | 场馆元素不能上产品（侵权） | ★★★ |

> 关键认知：**这五方经常不是同一个利益体**。签了经纪公司不等于能用歌词；拿到主办许可不等于能用场馆名。任何一项缺失，都要在方案里写成"缺失即降级"的分支，而不是赌它会有。

## 二、经纪公司档案（10 字段）

| 字段 | 说明 |
|------|------|
| 公司主体 | 全称 + 性质（唱片/经纪/工作室/厂牌） |
| 与本项目相关的权限 | 哪些品类它能拍板，哪些要上报 |
| 决策人 | 职级与风格（拍板快/层层上报/艺人主导） |
| 决策链长度 | 从接触到签约经过几人 |
| 历史审批周期 | 同类项目实际用了多少天（**要具体数字，不要"较快"**） |
| 审核轮次 | 设计稿几轮、每轮几天、谁能否决 |
| 分成与保底 | 常见比例、是否有保底、结算周期 |
| 排他习惯 | 是否多供应商并行、是否有独家条款 |
| 历史合作口碑 | 有无临期定案、口头承诺不落地、尾款拖欠 |
| 本案特殊结构 | 组合/双人/家族企业/艺人自营 等 |

## 三、授权范围矩阵（必须逐项落字）

| 维度 | 选项 | 本项目取值 | 影响 |
|------|------|-----------|------|
| 品类 | 全品类 / 限定品类（不含服装/食品/玩具） | | 决定 SKU 矩阵上限 |
| 渠道 | 仅现场 / 现场+线上 / 全渠道 | | **仅现场 → 长尾系数 λ 强制 = 1.0** |
| 地域 | 中国大陆 / 单城市 / 全球 | | 决定尾货能否转其他站 |
| 期限 | 演出日止 / 演出后 30-90 天 / 一年 | | 决定返单与长尾能否做 |
| 独家 | 独家 / 非独家 | | 非独家 → 产量保守，防同款竞价 |
| 衍生 | 是否允许二次创作（改色/改形/联名） | | 决定差异化空间 |
| 素材 | 可用素材清单（LOGO/主视觉/字体/歌词/音频） | | 缺素材 → 只能原创重绘 |
| 审批 | 审核轮次与时限 | | 决定 T-minus 倒排 |

> **三个最常被忽略的条款**：①渠道仅现场（长尾白算）②期限止于演出日（返单白做）③素材不含歌词（文案全部重写）。签约前必须逐条确认。

## 四、报批倒排（T-100 → T-45）

| 节点 | 动作 | 产出 | 卡点后果 |
|------|------|------|---------|
| T-100 | 找到真正能签字的**主体**（不是中间人） | 对接人 + 权限确认 | 找错人，白耗 2-3 周 |
| T-90 | 提交合作方案（品类/定价带/分成/量级） | 方案书 | 方案太虚 → 被搁置 |
| T-80 | 商务条款谈定（分成/保底/独家/结算） | 条款清单 | 反复改条款是最大时间黑洞 |
| T-70 | 设计方向过第一轮（艺人/经纪审美） | 方向确认 | 方向错 → 全部重画 |
| **T-60** | **拿到书面授权（LOI 或合同）** | 合同/授权书 | **未拿到 → 强制启动 Plan B（见下）** |
| T-55 | 素材交付（高清 LOGO/主视觉/字体授权） | 素材包 | 素材晚到 → 打样延期 |
| T-50 | 设计定稿两轮审核完成 | 终稿 | 此后只能"现货改装" |
| T-45 | 下单排产 | PO | 交期开始倒计时 |

**Plan B（T-60 未签约时的强制动作）**：全部 SKU 切到"零授权依赖"品类——贴纸/票根套/帆布袋/毛巾等仅用**通用文字与原创图形**，不碰艺人肖像、不印歌词、不用巡演视觉；同时把长周期品类（礼盒、金属、毛绒）改为**演后预售**（先收单再生产），把授权风险从"库存风险"转为"交付周期风险"。

## 五、合同 12 条要点

1. **授权主体与权限证明**（签约方须有权处分相关权利）
2. **授权品类清单**（正面列举，反面排除）
3. **销售渠道**（现场/线上/私域，是否含演后）
4. **授权期限**（含尾货处理期，建议演后 60-90 天）
5. **地域范围**（是否含其他巡演站）
6. **独家性**（独家则要求对方承诺不再授权同类）
7. **分成比例与计算基数**（按吊牌价还是实收、是否扣场地分成）
8. **保底与最低量**（有保底则必须做悲观情形测算）
9. **设计审核流程与时限**（写明"超时视为通过"，否则会被无限拖）
10. **素材使用范围**（LOGO/肖像/歌词/音频分别列，含二次修改权）
11. **质量与售后责任**（退换货、质量投诉由谁承担）
12. **违约与终止**（尤其"演出延期/取消"时的库存与费用分担）

> 第 9 条是最容易被忽略、也最救命的一条。没有"超时视为通过"，审核就会吃光你的生产窗口。

## 六、组合 / 双人 / 家族企业的特殊结构

| 结构 | 特征 | 对项目的影响 |
|------|------|-------------|
| **双人组合**（如凤凰传奇） | 两人五五分账、共同决策 | 肖像/签名/背书需**双方共同签署**；单人出镜的素材不能默认可用；沟通成本 ×2，但决策反而比单人工作室更快（长期稳定搭档，无经纪人换帅风险） |
| 艺人自营工作室 | 艺人本人即决策人 | 快，但审美否决权极硬，需前置过方向 |
| 大型唱片公司 | 版权强、流程长、法务重 | 慢，需预留 30-45 天；歌词/音频授权最易卡 |
| 家族/夫妻团队 | 决策集中 | 快，但专业度参差，需替对方补齐执行细节 |

## 七、风险信号（出现 2 条以上，直接按 🔴 处理）

1. 接触 3 周仍未确认"谁能签字"
2. 对方反复改条款但从未提"合同"
3. 同时接触 3 家以上供应商，且不告知评审标准
4. 口头承诺"肯定没问题"，但拒绝出书面 LOI
5. 距演出 60 天仍无设计审核排期
6. 素材迟迟不给，理由是"还在定"
7. 分成口径反复（吊牌价/实收/扣场地分成来回变）
8. 主办与经纪互相推"这个不归我管"

> 信号 8 是周杰伦案例的典型形态：**不是某一方拒绝，而是没有任何一方负责。**

## 八、谈判筹码清单（按稀缺性排序）

| 筹码 | 适用条件 | 话术方向 |
|------|---------|---------|
| 场馆档期稀缺性 | 场馆年度收官/闭馆前 | "以 2026 收官纪念为名做场馆联名"（对场馆方） |
| 场次差异化 | 多场连开/生日场 | "六场六个编号，生日场独立款"（对艺人方） |
| 内容能力 | 能做拍摄/传播素材 | 用内容置换授权费或分成 |
| 首场数据 | 已开票售罄 | 用票房证明量级，换更低的保底 |
| 长尾承诺 | 授权含线上 | 用"演后持续销售"换更长授权期 |
| 独家对价 | 愿付保底 | 换排他，防同款竞价 |

## 九、三种典型画像与应对

| 画像 | 特征 | 应对 |
|------|------|------|
| **周杰伦型（🔴 授权混乱）** | 顶流、多供应商、临期不定案 | 全案按"做不出来"设计：零开模、现货改装、演后预售；合同未签前不投一分钱设计与打样 |
| **凤凰传奇型（🟢 稳定体系）** | 巡演百场、单一大主办、批文连续 | 正常推进，但注意双人共签与曲库分属（唱片公司） |
| **新人/工作室型（🟡 快但专业度低）** | 决策快、无流程 | 替对方出流程表与审核时限，把"快"锁进书面 |

## 十、与 Gate A 的联动

授权评分（3-15 分，见 `artist-ip-ecosystem.md`）→ 交付模式：

| 评分 | 等级 | 动作 |
|------|------|------|
| 12-15 | 🟢 | 正常推进 |
| 8-11 | 🟡 | 交付模式降一级，全流程预留 15-20 天缓冲 |
| 3-7 | 🔴 | 不论 IP 多强，一律零开模 + 现货改装 + 演后预售，第 1 章明确写"最大风险是做不出来" |

> 评分再高也不能省略 T-60 的书面授权节点。流程是用来防"这次应该没问题"的。
