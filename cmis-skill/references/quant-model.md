# 量化模型：容量、销量、首批量、毛利

> 用途：把"感觉能卖多少"变成"可核算、可追溯、可校准"的数字。
> 读取时机：Layer 5 生成 SKU 后、Layer 6 定稿前。策划书第 8 章、第 10 章的数据全部出自本模型。

---

## 一、总漏斗公式

```
① 有效观演人次   N = 场次 × 可售座位 × 上座率 × (1 − 赠票/工作人员占比)
② 决策人次       D = N × w × k
③ 单SKU现场销量  Qᵢ = D × sᵢ × eᵢ
④ 单SKU总需求    Tᵢ = Qᵢ × λ            ← λ 为长尾系数
⑤ 项目流水       R = Σ (Tᵢ × Pᵢ)
⑥ 项目毛利       G = Σ [Tᵢ × (Pᵢ − Cᵢ)] − 固定成本
```

| 符号 | 含义 | 取值范围 | 说明 |
|------|------|---------|------|
| `N` | 有效观演人次 | 场馆额定座位 × 0.85-0.95（视野受限/搭建位）× 上座率 0.9-1.0 | 赠票/安保/媒体按 3-5% 扣除 |
| `w` | **整体购买意愿率** | 按圈层取值，见下表 | 买**至少一件**文创的人次占比，非件数 |
| `k` | **分流率系数** | 低 1.0 / 中 0.80-0.90 / 高 0.60-0.75 / 极高 0.40-0.60；再乘现场修正 0.85-1.0 | 来自 Layer 1.5 四维评分 + E类现场冲突 |
| `sᵢ` | 该SKU的**品类份额** | 见下方结构占比表 | 占决策人次的比例 |
| `eᵢ` | 情绪系数 | 0.85-1.15 | 与当前情绪热点强绑定 1.10-1.15；题材陈旧 0.85-0.90 |
| `λ` | **长尾系数** | 1.0-1.6，按圈层 | 演后 30-60 天需求倍数；授权不含线上销售时按 1.0 |
| `Pᵢ` | 零售价 | 见四象限价格带 | |
| `Cᵢ` | 单件完全成本 | 出厂价 + 包装 + 物流 + 分成 | 见第三节 |

> ⚠️ **只用低/基准/高三档输出区间**，不要给单点数字。单点数字看起来专业，实际上不可信，且会被客户当成承诺。

### w 与 λ 按圈层取值（v5.3）

| 圈层类型 | w | λ | 备注 |
|---------|---|---|------|
| 流量偶像型 | 0.25-0.35 | 1.0 | 现场即峰值，长尾弱 |
| 大众流行型 | 0.20-0.28 | 1.0-1.1 | 基准 |
| 创作/唱作型（民谣） | 0.18-0.26 | **1.3-1.6** | 赵雷型：结构反转 + 长尾长 |
| 摇滚/独立型 | 0.15-0.25 | 1.2-1.4 | 反塑料感，重工艺与平面 |
| 说唱/潮流型 | 0.22-0.32 | 1.0-1.2 | 服饰与配饰为主 |
| 资深唱将型 | 0.15-0.22 | 1.1-1.3 | 重决策、礼盒强 |

> 圈层判定与拆解见 `references/artist-archetypes.md`。**先判圈层，再取参数**——这是最容易出错的一步。
> 授权范围若不含"线上销售"，λ 必须按 1.0 算，否则会虚增长尾销量。

## 一.5｜三条口径（v5.3.1，实跑踩坑后写死）

> 这三条是字面执行原文会直接算错的地方，必须先读。

### 口径①：份额不是"分蛋糕"，人均件数要单独控

`sᵢ` 是**结构占比**（Σsᵢ = 1.0），不能直接乘决策人次——否则会得出"人均 0.43 件"，与本文件"Σ(sᵢ×eᵢ) 应落在 1.6-2.6"的校验线自相矛盾。

```
M(总件数) = D(决策人次) × 人均件数
Qᵢ        = M × sᵢ × eᵢ / ē        （ē = 全部 SKU 的 e 均值）
```

- 人均件数按矩阵厚度取：8-11 SKU → 1.6-2.2；12-16 SKU → 1.8-2.6
- 校验：`ΣQᵢ = M`，且 `Σsᵢ × 件均价 ≈ 加权客单价`

### 口径②：限量款按限量数反推，不参与份额分配

「限量 2,026 套」是**硬约束**，不是份额算出来的结果。实跑中出现过按份额法给出 6,853 套、虚增流水 ¥241 万的错误。

```
限量款：Q = 限量数（不乘任何系数）
常规款：M_可用 = M − Σ限量数，再按 sᵢ 归一化分配
```

> 判断法：包装上印了编号区间的，一律走限量口径；没有编号的一律走份额口径。两者不得混用。

### 口径③：完全成本必须含场地分成，否则毛利虚高 25-30 个点

```
Cᵢ = 出厂价 + 包装 + 物流仓储 + 分成(15-30% × Pᵢ) + 损耗(4% × Pᵢ)
```

只算出厂价时毛利会显示 80%+，加上分成与损耗后回落到 45-60%——这是很多方案"看起来很赚"的根源。

**Gate B 执行顺序**：先算 `Cᵢ` → 再算毛利率 → 与象限下限比对 → 不达标按「提价 → 压出厂价 → 改规格 → 降级为演后款」的顺序修，并记录修了什么。

## 二、品类份额 sᵢ 基准（来自 6 艺人 56 SKU 实证）

> 基准条件：**单项目 8-11 个 SKU**。份额 = 该**单一SKU**销量占项目总销量比例（实证归一化）。
> 与 `empirical-data.md` 的"功能组占比"配合使用：先用功能组确定结构，再在组内分配单 SKU 份额。

| 品类（单SKU） | 实证区间 | 建议取值 | 备注 |
|------|---------|---------|------|
| 应援棒/LED棒 | 12-35% | 15-22% | 张杰 35% 属单场超大容量+SKU精简的特例 |
| 票根套/票夹/卡套 | 9-26% | 15-20% | 入场刚需，失败率最低 |
| 亚克力小件（钥匙扣/卡套/发绳） | 13-30% | 12-18% | 含粉丝圈"谷子"消费；发绳类套装可到 20% |
| 异形/毛绒/IP形象件 | 6-26% | 10-18% | 差异化越高份额越高（Q版钥匙扣达 26%） |
| 金属徽章（含套组/盲盒） | 9-17% | 9-14% | 盲盒机制可上浮 30% |
| 冰箱贴（含互动款） | 8-20% | 8-15% | NFC/异形款取上限 |
| 毛巾 | 7-10% | 7-10% | 现场挥动传播刚需 |
| T恤 | 5-12% | 7-10% | **实证中T恤份额并不高**，价值在毛利与品牌，不在走量 |
| 帽子 | 5-10% | 5-8% | 刺绣款表现更好 |
| 卫衣/夹克/外套 | 2-4% | 2-4% | 客单价高、量小，谨慎压货 |
| 实体CD/黑胶/礼盒 | 2-4% | 1-4% | 收藏型，靠限量而非份额 |
| 极限限量款（≤3000件） | 0.3-1% | 按限量数反推 | 不适用份额法，直接按限量数定产 |

**SKU 数量的归一化修正**：

| 项目SKU数 | 单SKU份额修正 |
|-----------|--------------|
| 5-7（S档） | ×1.25-1.35 |
| 8-11（M档） | ×1.00（基准） |
| 12-16（L档） | ×0.75-0.85 |

> 校验逻辑：所有 SKU 的 `sᵢ × eᵢ` 之和应落在 **1.6-2.6**（即人均购买 1.6-2.6 件）。若算出人均 4 件以上，说明份额高估；低于 1.2 件说明矩阵过薄或定价过高。

## 三、成本与毛利

### 单件完全成本

```
C = 出厂价 + 包装 + 物流仓储 + 渠道/场地分成 + 损耗（3-5%）
```

| 成本项 | 参考口径 |
|--------|---------|
| 出厂价 | 见 `sku-library.md` 成本参考；小批量（<3000件）上浮 15-30% |
| 包装 | 单品 ¥2-8；礼盒 ¥15-60 |
| 物流仓储 | 单件 ¥3-10；异地配货 +30-50%；含磁铁/电池需陆运，成本与时效另计 |
| 场地/主办分成 | **15-30%（以合同为准）**，是很多方案漏算的最大一项 |
| 损耗/赠品/媒体 | 3-5% |

### 各象限毛利率下限（Gate B 判定用）

| 象限 | 价格带 | 毛利率下限 | 说明 |
|------|-------|-----------|------|
| 引流款 | ¥15-49 | ≥45% | 允许低毛利，但要覆盖现场运营成本 |
| 利润款 | ¥69-199 | ≥55% | 项目现金流主力 |
| 品牌款 | ¥199-499 | ≥50% | 可以略低，换调性与传播 |
| 稀缺款 | ¥299-999+ | ≥55% | 编号/工艺溢价必须真正体现在成本结构里 |

### 盈亏平衡

```
保本销量 = 固定成本 ÷ 单件边际贡献
固定成本 = 设计费 + 打样/开模 + 摊位/物料 + 拍摄/内容 + 不可分摊物流
```

固定成本典型量级（单项目）：设计 3-15 万；打样开模 1-8 万；现场摊位与物料 2-10 万；内容拍摄 1-5 万。
方案中必须给出：**总固定成本 / 保本总流水 / 各SKU是否单独跨越其MOQ**。

## 四、首批订货量

```
首批 Pᵢ = Qᵢ × (1 − π) × (1 + σ)          ← 只覆盖现场，不含长尾
返单计划 = Qᵢ × (λ − 1) × 返单比例        ← λ > 1.2 时必须做
```

> λ>1.2（创作/民谣、摇滚、唱将型）时，若首批就按总需求 T 下单，会在现场压货；若完全不留返单产能，会错过长尾。正确做法是**首批小而快、返单覆盖长尾**。

| 参数 | 含义 | 取值 |
|------|------|------|
| `π` | 预售占比（提前售出的比例） | 有预售机制 0.15-0.35；无预售 0 |
| `σ` | 安全库存率 | 可补货 0.10-0.15；单场不可补货 0.15-0.25；异地/多场 0.25-0.35 |

**硬约束（依次校验，取最小值）**：

1. `Pᵢ ≥ MOQ`（低于MOQ时：提价、改规格、或与同系列合并下单）
2. `Pᵢ ≥ 预售量 / (1 − 取消率 0.05)`
3. `Pᵢ ≤ 供应商产能 × 可用天数`
4. 总首批金额 ≤ 预算上限

### 典型 MOQ 参考

| 品类 | MOQ |
|------|-----|
| 贴纸/纸质印刷 | 1,000-3,000 |
| 亚克力件 | 500-1,000 |
| 金属徽章 | 500-1,000（套组按套） |
| T恤（丝印） | 300-500/色 |
| 毛巾 | 500-1,000 |
| 毛绒/异形 | 500-1,000（开版费高） |
| LED类 | 1,000-3,000（含方案与认证） |
| 精装礼盒 | 300-500 |

### 补货与降价决策规则（现场执行用）

| 信号 | 判定 | 动作 |
|------|------|------|
| 首日售罄率 ≥70% 且距下一场 ≥5天 | 强需求 | 立即加急补货（走 `supply-chain.md` 加急通道） |
| 首日售罄率 50-70% | 正常 | 不补或小批补，观察第二场 |
| 首日售罄率 <40% | 高库存风险 | 停止补货；启动套装组合/限购解除/演后折扣 |
| 演出结束后库存 >30% | 长尾处理 | 转官方店长尾（限时）、或作为下一站预热赠品 |

## 六、预测偏差的三个来源（v5.3，复盘时按此归因）

预测错了，不要含糊地说"市场不好"。偏差只可能来自三处，逐项归因：

| 来源 | 表现 | 典型反例 | 修正动作 |
|------|------|---------|---------|
| **① 总量（w×k）** | 整体买的人比预想多/少 | 赵雷：误判"民谣粉丝保守=不消费" | 调 w，并检查是否把"表达方式内敛"错读成"购买意愿低" |
| **② 结构（s）** | 总量对，但品类错配 | 赵雷：应援类失效，帽/钥匙扣爆；连补货 | 调 s 与圈层结构修正系数 |
| **③ 长尾（λ）** | 现场卖完就以为结束，实际演后仍有需求 | 赵雷：演后一个月"戒断反应" | 调 λ，补返单与长尾运营 |

> 统计上，**结构错误比总量错误更常见、也更致命**——因为它同时导致"该多的没多、该少的压货"。
> 复盘必须写清：这次主要错在①②③哪一个，占多大比例。

## 七、校准机制（长期专业化的关键）

每场结束后 30 天内，把实际数据回填 `empirical-data.md`，并记录：

| 字段 | 用途 |
|------|------|
| 预测 vs 实际销量（分SKU偏差率） | 修正 sᵢ 与 eᵢ |
| 实际购买意愿 w | 修正 w 区间 |
| 实际客单价与价格弹性 | 修正定价模型 |
| 售罄/滞销 SKU 的原因 | 修正符号推导与差异化判断 |

> 偏差率 >30% 的 SKU，必须写下"为什么错了"一句话。三次同类偏差 → 修改基准表。
> 没有回填的项目，视为未完成交付。
